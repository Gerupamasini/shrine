# 夏陰 — NATSUKAGE

1994年8月、東北の山あいの集落。麓の鳥居から200段の石段を登って山上の神社へ向かい、境内の外れから夕暮れの村・田んぼ・川・重なる山並みを見下ろす。Three.js + TypeScript + Vite で作った、一人称で歩けるブラウザ向けの3Dマップです。

**現状**：探索・地形・建築・植生・水・光・音・Unity用データまで、すべて実際に動く制作版です。写実性は大きく上がりましたが、AAAタイトルの最終品質には届いていません。届いていない点は「既知の限界」に書いています。素材の出典とライセンスは [ASSET_CREDITS.md](ASSET_CREDITS.md) にあります。

## 起動

Node.js 22以上、WebGL2対応のブラウザ（デスクトップのGPUを推奨）が必要です。

```sh
npm ci
npm run dev
```

表示されたアドレスを開き、「山里を歩く」を押します。素材はすべて同梱されており、起動後に外部サーバーへは接続しません。

地形・配置・モデル・テクスチャ・音は、ビルドごとの版（`?v=<コミット>-<ビルド時刻>`）を付けて読み込みます。GitHub Pages は全ファイルを10分間キャッシュするため、版がないと、更新直後に新しいプログラムと古い地形データが混ざって表示されることがありました。

```sh
npm run build          # 型チェック + 本番ビルド（dist/）
npm run preview        # 本番ビルドの確認
npm test               # 地形・石段・川・水田・配置・材質・音源ライセンスのデータ検証
npm run test:browser   # Playwright：石段の登坂・衝突・設定・画面（GPUなしでも可、遅い）
```

URLパラメータは次のとおりです。

- `?quality=low|standard|high`：描画品質
- `?time=17.5`：時刻
- `?place=lookout`：開始地点

開始地点には `foot`、`stairs`、`shrine`、`lookout`、`village`、`paddies`、`river`（橋の上）、`weir`（堰）、`tanada`（川向の棚田の上）、`temple`（寺）、`sawa`（沢）、`clinic`（診療所）を指定できます。

## 操作

| 操作 | キー |
|---|---|
| 移動 | WASD |
| 視点 | マウスを動かすだけで見回せる（クリック不要）。カーソルを画面の左右の端に置くと、その方向へ回り続ける。クリックするとポインタロック（端で止まらずに回せる。Escで解除） |
| 走る | Shift（約7.8m/s。歩きは約1.5m/s） |
| ジャンプ | Space（走りながらでも可。空中では慣性を保ち、着地直前の入力も受け付ける） |
| マウス解除 | Esc |
| フリーカメラ（撮影用、衝突なし） | F、Q/Eで上下 |
| 地図 | M（全体図。ドラッグで移動、ホイールで拡大、◆をクリックでその場所へ。M / Esc で閉じる）。左下のミニマップは進行方向が上で、クリックでも全体図が開く。表示の有無は設定で切り替え |
| UIの表示切替 | H |
| 時刻（17:00〜19:00）・画質・移動先・音・地図・診断表示 | 右上の「設定」 |

歩行はRapierのキャラクターコントローラーで判定します。

- 地形は16-bitの高さ場コライダー
- 石段は各フライトに踏面の段鼻を結ぶ連続スロープを置き、蹴上げに引っかからない
- 建物・鳥居・灯籠・狛犬は箱、幹は円柱のコライダー

## 世界の構成（1単位 = 1m、+Y上、北 = −Z）

| 要素 | 内容 |
|---|---|
| 地形 | 1.5km四方、1281²の16-bit高さ場（約1.17m間隔）。南北に延びる細い谷（谷底の幅130〜300m）がゆるく蛇行し、東西から支谷が合流する。山はノイズではなく浸食モデル（`tools/world/region.py`）で作り、沢と枝分かれした尾根を持つ（地図内の稜線は谷底から90〜145m）。地図の外は、周囲1.6kmが同じモデルの山、その先が遠景の山並み（14km四方）。西北西には夕日が谷へ差し込む鞍部がある |

| 神社 | 入母屋造の拝殿（向拝・注連縄・鈴）、流造の本殿と玉垣、石と朱塗りの鳥居、春日灯籠、阿吽の狛犬、手水舎、社務所、絵馬掛け、賽銭箱、注連縄の御神木、石垣と見晴らしの柵 |
| 村 | 約80棟。県道沿いの町場（よろず屋・酒屋・豆腐屋・理容店・郵便局・駐在所・農協と農業倉庫・地区公民館・火の見櫓）の南北に家が集まり、北の沢の出口に小さな一群がある。集落ごとに成り立ちを変え、中里は茅葺きの大きな農家が道から離れて建つ古い農家集落、宮下は神社の下で参道の分かれ道に集会所を持つ集落、下宿は旧道沿いに瓦の家が詰まって並ぶ家並み、南沢はトタン屋根とブロック塀の新しい家が混ざる。川向は棚田の斜面の中ほどを等高線沿いに通る道に家が並ぶ。田の中に散居6軒。東の山裾に小さな寺（瑞雲寺：本堂・山門・鐘楼・六地蔵・墓地）、村の南端に診療所。道に面した家は道を向き、奥の農家は南向きで北と西に居久根を持つ。農家は母屋・納屋・作業小屋で庭を囲む。道路は県道（6m舗装、中央線・外側線）、町道（舗装）、農道（砂利）、私道（短い砂利道）に分かれる。県道は谷の奥でトンネル（上沢隧道）へ入る。切土は1:1、盛土は1:1.5の法面。丸ポスト、電話ボックス、自動販売機、バス停、石塔、石垣、ブロック塀、側溝、電柱と電線（街灯は日暮れに点灯）、テレビアンテナ、風呂の煙突、プロパンガスのボンベと灯油のホームタンク、物干し台、軽トラック、生活小物 |

| 用水・沢 | 谷底の高い側（県道側）の田には、東の支谷の沢（奥沢・宮沢）から水を引く。沢を少し登った所の取水堰から、幅0.9mのコンクリートの幹線用水路が県道の下を管でくぐり、県道の盛土の足元を、潤す田より高い水位で下流へ流れる。農道に沿う支線水路（9本）が田の間を通って川へ落ちる。私道や農道が横切る所は蓋掛け。大きい宮沢は県道の短い橋の下を、小さい奥沢は暗渠でくぐり、田の中は三面張りの水路で本流へ注ぐ |
| 植生 | 杉・檜・赤松・広葉樹・欅・竹を約5.5万本。山は約120mの林分に分かれ、村に近い低い斜面は杉・檜の植林地（林分ごとの向きの列に、樹齢をそろえて植える）、所々に植えて数年の若い林と伐採跡（切り株・低木）、奥の斜面と尾根は群生と空き地のある広葉樹の自然林（尾根に赤松）。林縁は低い木と低木。川沿いの河畔林・中州の柳・水害防備林の竹林、砂州のツルヨシ、土手のススキ。若木・低木の下層植生（固定シードで生成、群生）、シダ・低木・雑草・苔むした岩・切り株・倒木。近景の草はPoly Havenの写真の草株、遠めは手続き的な草、稲は実行時に生成 |

すべての配置は固定シードで再現できます。

## 光と空気

- **太陽**：NOAAの近似式による天文計算（1994年8月8日、北緯38.32°・東経141.02°、JST）。18:00で方位285.6°・高度6.7°、19:00で日没後（−4.5°）
- **直射光**：大気減衰の近似で色温度を変える（湿った夏の谷を想定した光学的厚さで、18:00で約2900K、17:00で約4200K、日没前は赤橙）
- **空**：夏の積雲が散る夕方の写真（Poly HavenのCC0 HDRI `kloppenheim_06_puresky`、太陽高度4.7°）を太陽方位に合わせて回転し、夏の夕方の湿った色に補正（雲の太陽側を暖色に）。太陽円盤は解析的に描画
- **環境光**：同じHDRIから太陽を除いてIBLとして使用。直射光と空の光の比は、晴れた湿った夕方の実測に近い約6:1（直達日射と水平面の散乱日射）にしている。以前は空の光が強すぎ（約2:1）、谷全体が青灰色に沈んでいた
- **影**：カスケードシャドウ3段（品質に応じて1024〜4096）
- **大気遠近法**：高さで減衰する霞を全マテリアル共通で適用。太陽側に暖色の前方散乱を加える。谷底には、地表付近だけに溜まる夕方の湿った霞（スケールハイト約17m）を重ねる
- **ポストエフェクト**：深度のみのSSAO（接地感）、ACESトーンマッピング、弱いブルーム、色調補正（彩度・暖色のハイライト）、周辺減光・粒子
- **植物**：葉の透過光（逆光で葉が光る）。樹冠の法線は樹冠の形に沿わせ、裏面でも反転しない（樹冠の日なたと日陰がまとまって見える）。風で樹木・草・稲が揺れ、田には風の明暗の波が渡る。遠めの稲は、葉先を表す3層のシェル＋基底層で厚みを出している
- **水**：水際はピクセルごとに高さ場から河床の高さを読んで決め、砂州との境を地形に一致させる。浅い所ほど透けて川底の石が見える。落差工と堰の越流は白い筋の入った薄い水の膜、その下流は泡のまだら、瀬は浅い所だけ白く砕ける。反射は、対岸の護岸の高さと距離・その先の森の濃さで空と岸を描き分け、西日を受ける東岸の護岸は明るく映る。浅い角度ほど鏡面になる（フレネル）
- **夕暮れの灯り**：時刻に応じて、家の窓明かり・自販機・街灯が点いていく
- **煙**：8軒の風呂の煙突と茅葺きの煙出しから、細い煙が夕方の風に流れながら20mほど昇る（太陽の側から見ると明るく透ける）
- **精霊とんぼ**：ウスバキトンボが田と草地の上1〜3.5mを輪を描いて滑空する。カメラの周りの区画に固定して配置し、森・道・水の上には出ない。日没後は数が減る

## 音（BGMなし）

- **ヒグラシ**：Wikimedia Commonsの実録（Σ64、CC BY 4.0）
  - 森の中の5点に固定したHRTF立体音源で、それぞれ再生位置と速度を変え、96秒の素材が単調に繰り返して聞こえないようにしている
  - 遠景の合唱として、同じ素材のステレオ版も重ねている
  - 時刻とともに盛衰する
- **川・風・葉擦れ**：実録ではなく、Web Audioでノイズから合成している
  - 川は、近くの落差工・堰2か所（落差に応じた音量、堰がいちばん大きい）と、足もとの瀬の3点から鳴る
- **夕方のチャイム**：18:00に、火の見櫓の防災無線スピーカーから「夕焼け小焼け」が流れ、山に反響する。旋律は草川信（1923年作曲、1948年没。パブリックドメイン）。歌詞は使わず、Web Audioの電子チャイムで合成している
  - 18:00で歩き始めると16秒後に鳴る。設定で時刻を18:00の前から後へ動かしても鳴る
  - 風は高台ほど強い

## 既知の限界（完成品と偽らないために）

作業の途中経過とやり残しは [docs/HANDOFF.md](docs/HANDOFF.md) にまとめています。

- **建築**：手続き的に作ったモデルです。柱・軒の反り・屋根の厚み・格子・注連縄までは作っていますが、組物（斗栱）や彫刻、瓦1枚ずつの形状はテクスチャで表現しています。写真測量した建築には及びません。狛犬はメタボールで作った摩耗した石像で、細部の彫りはありません。
- **樹木**：Poly Havenの実写の葉を焼いたカードと独自の枝の生成で作っています。スギとヒノキの葉の形は、モミの若木の葉を元にした近似です。遠景はビルボードです。
- **音**：実録はヒグラシのみです。川の音・風・他のセミ・鳥は、実録素材を取得できなかったため、合成音にしているか、入れていません。
- **葉の縁**：品質「軽量」はMSAAを使わないため、葉は alpha-to-coverage ではなく単純な切り抜きで描きます。縁は少しギザつきますが、透けて見えることはありません。
- **性能**：この開発環境にはGPUがなく、SwiftShaderで描画を確認しました。実GPUでの1080p・60fpsは未計測です。品質「標準」の負荷の内訳は [docs/PERFORMANCE_BUDGET.md](docs/PERFORMANCE_BUDGET.md) にあります。
- **未実装**：テクスチャ圧縮（KTX2）、樹木LODのクロスフェード。光芒は画面空間の簡易版です。
- **畑の作物**：写真測量した植物（Poly Havenのイラクサ・雑草・低木）を代役に使っています。ナス・枝豆・里芋・葉物の実際の種ではありません。
- **川**：護岸の石積みとブロックは写真のテクスチャを貼った面で、石1個ずつの凹凸はありません。川幅・水深は景観上の値で、流域面積や流量から求めたものではありません。越流や白波は形状ではなくシェーダーの模様で、水しぶきの粒子はありません。川の水量は夏の平水を想定した固定値で、増水はしません。ツルヨシとススキは写真の草株を縦に伸ばした代用です。
- **地図**：地名（上沢・奥沢・中里など）、川の名前（上沢川）、神社名（熊野神社）、県道の番号、トンネル名はすべて架空です。地図は1:25,000の地形図の描き方に倣っていますが、縮尺は画面の拡大に合わせて変わります（縮尺棒で表示）。
- **トンネル**：坑口の中は照明が奥へ続いて見えますが、入口から先へは進めません（地図の外へ抜ける道です）。
- **看板**：店名・局名は架空です。字は Noto Serif JP から看板に使う字だけを取り出したサブセットで、別の字を足すときは `python3 tools/assets/fetch_sign_font.py` を実行し直します。
- **遠景の山**：地図の外は、中心から約2.6km（軽量は1.8km）まで木のビルボードを置いて、尾根に木の輪郭を出しています。その先は、樹冠のかたまりを描いた森の色と霞で表現しています。近づいて見るための地形ではありません。
- **境内の光**：18:00頃は西側の杉林が夕日を遮るため、境内はほぼ日陰になります。見晴らしからは、杉の幹の間に夕日の空が見えます。
- **Sketchfabの建築モデル**：ログインが必要なため取得していません。
- **参照先**：塩竈神社と『ひぐらしのなく頃に』は雰囲気の参考に留めています。建物・地図・配置は独自設計です。
