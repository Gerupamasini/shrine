# 夏陰 — NATSUKAGE

1994年8月、東北の山あいの集落。麓の鳥居から200段の石段を登って山上の神社へ向かい、境内の外れから夕暮れの村・田んぼ・川・重なる山並みを見下ろす。Three.js + TypeScript + Vite で作った、一人称で歩けるブラウザ向けの3Dマップです。

**現状**：探索・地形・建築・植生・水・光・音・Unity用データまで、すべて実際に動く制作版です。写実性は大きく上がりましたが、AAAタイトルの最終品質には届いていません。届いていない点は「既知の限界」に書いています。素材の出典とライセンスは [ASSET_CREDITS.md](ASSET_CREDITS.md) にあります。

## 起動

Node.js 22以上、WebGL2対応のブラウザ（デスクトップのGPUを推奨）が必要です。

```sh
npm ci
npm run dev
```

表示されたアドレスを開き、「山里を歩く」を押します。素材はすべて同梱されており、起動後に外部サーバーへは接続しません。

地形・配置・モデル・テクスチャ・音は、ビルドごとの版（`?v=<コミット>-<ビルド時刻>`）を付けて読み込みます。GitHub Pages は全ファイルを10分間キャッシュするため、版がないと、更新直後に新しいプログラムと古い地形データが混ざって表示されることがありました。

```sh
npm run build          # 型チェック + 本番ビルド（dist/）
npm run preview        # 本番ビルドの確認
npm test               # 地形・石段・川・水田・配置・材質・音源ライセンスのデータ検証
npm run test:browser   # Playwright：石段の登坂・衝突・設定・画面（GPUなしでも可、遅い）
```

URLパラメータは次のとおりです。

- `?quality=low|standard|high`：描画品質
- `?time=17.5`：時刻
- `?place=lookout`：開始地点

開始地点には `foot`、`stairs`、`shrine`、`lookout`、`village`、`paddies`、`river`（橋の上）、`weir`（堰）、`tanada`（川向の棚田の上）を指定できます。

## 操作

| 操作 | キー |
|---|---|
| 移動 | WASD |
| 視点 | マウス（クリックでポインタロック。使えない環境ではドラッグ） |
| 走る | Shift（約7.8m/s。歩きは約1.5m/s） |
| ジャンプ | Space（走りながらでも可。空中では慣性を保ち、着地直前の入力も受け付ける） |
| マウス解除 | Esc |
| フリーカメラ（撮影用、衝突なし） | F、Q/Eで上下 |
| UIの表示切替 | H |
| 時刻（17:00〜19:00）・画質・移動先・音・診断表示 | 右上の「設定」 |

歩行はRapierのキャラクターコントローラーで判定します。

- 地形は16-bitの高さ場コライダー
- 石段は各フライトに踏面の段鼻を結ぶ連続スロープを置き、蹴上げに引っかからない
- 建物・鳥居・灯籠・狛犬は箱、幹は円柱のコライダー

## 世界の構成（1単位 = 1m、+Y上、北 = −Z）

| 要素 | 内容 |
|---|---|
| 地形 | 1.2km四方、1025²の16-bit高さ場（約1.17m間隔）。南北に延びる谷、四方の山、遠景（14km四方の低解像度の山並み）。西北西には夕日が谷へ差し込む鞍部がある |
| 石段 | 200段（蹴上げ17.5cm・踏面34cm・幅5.2m）。50段×4フライト、3.5mの踊り場×3。麓（7.0m）から境内（42.0m）まで35m登る。花崗岩ブロックを1段に2〜3枚、摩耗・苔・側石付き |
| 神社 | 入母屋造の拝殿（向拝・注連縄・鈴）、流造の本殿と玉垣、石と朱塗りの鳥居、春日灯籠、阿吽の狛犬、手水舎、社務所、絵馬掛け、賽銭箱、注連縄の御神木、石垣と見晴らしの柵 |
| 村 | 62軒（瓦22、うち2階建て11・茅葺き20・トタン被せ14・土蔵造り6。L字の曲り家8）。東の山裾の道沿いに6つの集落、川向こうの山裾に「川向」の6軒、田の中に居久根で囲まれた散居の農家9軒。家はすべて南向き（棟は東西、谷側へ少し振る）で、土の前庭、庭に向いた納屋、家庭菜園、北と西の居久根（杉・欅）、庭の柿、道へ下る小道がある。火の見櫓（半鐘・防災無線のスピーカー）と消防の器具置場、丸ポスト、集落の境の石塔、石垣、ブロック塀、側溝、電柱と電線（街灯は日暮れに点灯）、テレビアンテナ、風呂の煙突、地蔵、バス停、自動販売機、軽トラック、生活小物 |
| 田畑 | 谷底の不整形な146区画（稲122、畑20、休耕4）と、川向の山裾の棚田51枚（標高6.7〜17.5m、1.3mずつの段。7枚は耕作放棄でススキと雑草）。谷底は山裾から川へ向けて緩く下がるので、田は少しずつ段になる。畦・法面付き。畑と家庭菜園は畝のテクスチャ（Poly Haven `farm_furrows`）と、畝に揃えた作物の列（約8.2万株） |
| 川 | 谷の西寄りの小河川。河床幅7〜15mを石積み・間知ブロックの護岸（高さ1.1〜1.9m、天端コンクリート）と土羽の堤防が挟み、3〜6mの低水路が交互砂州の間を蛇行する（淵と瀬）。落差工10か所、取水口付きの固定堰1か所、そこから田へ向かう幅1.2mの用水路、洗い場の石段2か所、中央に橋脚のある農道の橋。東岸の堤防に轍のある管理用通路 |
| 植生 | 杉・檜・赤松・広葉樹・欅・竹を約4.1万本（川沿いの河畔林・中州の柳・水害防備林の竹林を含む）。砂州のツルヨシ、土手のススキ。若木・低木の下層植生（固定シードで生成、群生）、シダ・低木・雑草・苔むした岩・切り株・倒木。近景の草はPoly Havenの写真の草株、遠めは手続き的な草、稲は実行時に生成 |

すべての配置は固定シードで再現できます。

## 光と空気

- **太陽**：NOAAの近似式による天文計算（1994年8月8日、北緯38.32°・東経141.02°、JST）。18:00で方位285.6°・高度6.7°、19:00で日没後（−4.5°）
- **直射光**：大気減衰の近似で色温度を変える（18:00で約3200K）
- **空**：雲のある写真（Poly HavenのCC0 HDRI）を太陽方位に合わせて回転し、夏の夕方の湿った色に補正（雲の太陽側を暖色に）。太陽円盤は解析的に描画
- **環境光**：同じHDRIから太陽を除いてIBLとして使用
- **影**：カスケードシャドウ3段（品質に応じて1024〜4096）
- **大気遠近法**：高さで減衰する霞を全マテリアル共通で適用。太陽側に暖色の前方散乱を加える。谷底には、地表付近だけに溜まる夕方の湿った霞（スケールハイト約17m）を重ねる
- **ポストエフェクト**：深度のみのSSAO（接地感）、ACESトーンマッピング、弱いブルーム、色調補正（彩度・暖色のハイライト）、周辺減光・粒子
- **植物**：葉の透過光（逆光で葉が光る）。風で樹木・草・稲が揺れ、田には風の明暗の波が渡る。遠めの稲は、葉先を表す3層のシェル＋基底層で厚みを出している
- **水**：水際はピクセルごとに高さ場から河床の高さを読んで決め、砂州との境を地形に一致させる。浅い所ほど透けて川底の石が見える。落差工と堰の越流は白い筋の入った薄い水の膜、その下流は泡のまだら、瀬は浅い所だけ白く砕ける。反射は、対岸の護岸の高さと距離・その先の森の濃さで空と岸を描き分け、西日を受ける東岸の護岸は明るく映る。浅い角度ほど鏡面になる（フレネル）
- **夕暮れの灯り**：時刻に応じて、家の窓明かり・自販機・街灯が点いていく
- **煙**：8軒の風呂の煙突と茅葺きの煙出しから、細い煙が夕方の風に流れながら20mほど昇る（太陽の側から見ると明るく透ける）
- **精霊とんぼ**：ウスバキトンボが田と草地の上1〜3.5mを輪を描いて滑空する。カメラの周りの区画に固定して配置し、森・道・水の上には出ない。日没後は数が減る

## 音（BGMなし）

- **ヒグラシ**：Wikimedia Commonsの実録（Σ64、CC BY 4.0）
  - 森の中の5点に固定したHRTF立体音源で、それぞれ再生位置と速度を変え、96秒の素材が単調に繰り返して聞こえないようにしている
  - 遠景の合唱として、同じ素材のステレオ版も重ねている
  - 時刻とともに盛衰する
- **川・風・葉擦れ**：実録ではなく、Web Audioでノイズから合成している
  - 川は、近くの落差工・堰2か所（落差に応じた音量、堰がいちばん大きい）と、足もとの瀬の3点から鳴る
- **夕方のチャイム**：18:00に、火の見櫓の防災無線スピーカーから「夕焼け小焼け」が流れ、山に反響する。旋律は草川信（1923年作曲、1948年没。パブリックドメイン）。歌詞は使わず、Web Audioの電子チャイムで合成している
  - 18:00で歩き始めると16秒後に鳴る。設定で時刻を18:00の前から後へ動かしても鳴る
  - 風は高台ほど強い

## データと再生成

| 出力 | 原本・生成ツール |
|---|---|
| `public/world/heightmap.r16` / `.png`（16-bit）、`splat0/1.png`、`vegetation-mask.png`、`paddy-level.png`、`far-heightmap.png` | `tools/world/generate_world.py` |
| `public/world/scene.json`（石段・建物・川・道・電線・水田・目印）、`vegetation.json`、`clutter.json` | 同上 |
| `public/world/materials.json`（材質名 → 写真PBRの対応表。ランタイムとUnityで共用） | 手動で管理 |
| `public/assets/models/architecture/*.glb`（`river-works.glb` は `scene.json` の川のデータから世界座標で生成） | `tools/architecture/build.mjs` |
| `public/assets/models/trees/*.glb`（LOD0/LOD1、風の重みは頂点カラー） | `tools/trees/build-trees.mjs` |
| `public/assets/foliage/*`（写真の葉カード） | `tools/bake/bake-cards.mjs` → `compose_atlases.py` |
| `public/assets/textures/*`、`sky/*`、`models/props/*`、`audio/*` | `tools/assets/fetch.py` → `process_*.{py,mjs,sh}` |

```sh
pip install -r requirements-assets.txt
python3 tools/assets/fetch.py                 # Poly Haven / Commons から .cache/ へ取得
python3 tools/assets/process_textures.py
node tools/assets/process_models.mjs
tools/assets/process_audio.sh
python3 tools/world/generate_world.py
node tools/trees/build-trees.mjs
node tools/architecture/build.mjs
node tools/bake/bake-cards.mjs && python3 tools/bake/compose_atlases.py
python3 tools/assets/catalog.py               # docs/asset-manifest.json と ASSET_CREDITS.md
```

地形と配置だけを作り直すときは `npm run world`（`generate_world.py` と建築モデル）、全部をやり直すときは `npm run assets` を使います。

確認用のツールもあります。

- `node tools/shot.mjs <出力先> name:place:方位:俯角[:時刻]`：任意視点の撮影
- `node tools/walk-test.mjs`：登坂テスト
- `python3 tools/world/preview.py`：地図の俯瞰

## 既知の限界（完成品と偽らないために）

- **建築**：手続き的に作ったモデルです。柱・軒の反り・屋根の厚み・格子・注連縄までは作っていますが、組物（斗栱）や彫刻、瓦1枚ずつの形状はテクスチャで表現しています。写真測量した建築には及びません。狛犬はメタボールで作った摩耗した石像で、細部の彫りはありません。
- **樹木**：Poly Havenの実写の葉を焼いたカードと独自の枝の生成で作っています。スギとヒノキの葉の形は、モミの若木の葉を元にした近似です。遠景はビルボードです。
- **音**：実録はヒグラシのみです。川の音・風・他のセミ・鳥は、実録素材を取得できなかったため、合成音にしているか、入れていません。
- **葉の縁**：品質「軽量」はMSAAを使わないため、葉は alpha-to-coverage ではなく単純な切り抜きで描きます。縁は少しギザつきますが、透けて見えることはありません。
- **性能**：この開発環境にはGPUがなく、SwiftShaderで描画を確認しました。実GPUでの1080p・60fpsは未計測です。品質「標準」の負荷の内訳は [docs/PERFORMANCE_BUDGET.md](docs/PERFORMANCE_BUDGET.md) にあります。
- **未実装**：テクスチャ圧縮（KTX2）、樹木LODのクロスフェード。光芒は画面空間の簡易版です。
- **畑の作物**：写真測量した植物（Poly Havenのイラクサ・雑草・低木）を代役に使っています。ナス・枝豆・里芋・葉物の実際の種ではありません。
- **川**：護岸の石積みとブロックは写真のテクスチャを貼った面で、石1個ずつの凹凸はありません。越流や白波は形状ではなくシェーダーの模様で、水しぶきの粒子はありません。川の水量は夏の平水を想定した固定値で、増水はしません。ツルヨシとススキは写真の草株を縦に伸ばした代用です。
- **遠景の山**：遠い尾根は樹木を描かず、手続き的な森の色と霞で表現しています。近づいて見るための地形ではありません。
- **境内の光**：18:00頃は西側の杉林が夕日を遮るため、境内はほぼ日陰になります。見晴らしからは、杉の幹の間に夕日の空が見えます。
- **Sketchfabの建築モデル**：ログインが必要なため取得していません。
- **参照先**：塩竈神社と『ひぐらしのなく頃に』は雰囲気の参考に留めています。建物・地図・配置は独自設計です。
