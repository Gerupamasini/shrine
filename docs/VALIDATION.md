## 地形・接触

- 水田内部は高さ差3.5cm未満。宅地は低地より約1.15m高く、建物の基礎が地形に接する。
- 川の水面は下流へ単調に下がる。上流の山に細く深い溝を通していた生成を修正し、標高の上がる広い源流の谷へ接続。南の出口を開いた。
- Rapierで実際に200段を往復。段数分のテレポートではない。登頂時の目線は約39.676m。
- 拝殿の前でz=-132.175m付近に停止。下山先の高い土地では地面から目線まで約1.67m。旧版の固定標高の期待値ではなく、地形への接地で検証。
- 描画と物理の地形は同じ非均一格子。村・川付近は2.34375m、外周は4.6875m。橋、木の幹、建物に簡略化コライダーを持つ。

## 画像と負荷

起動時はモデルだけでなくテクスチャのデコード完了を待ち、画像が壊れている場合は開始を許可しない。Git LFSの参照文字列を画像として取得していた問題を修正し、PNG/JPEGの実体を検証するテストを追加した。

最終地形の本番スモークでの標準モード観測：麓1,278,562三角形・102 calls、展望地点1,151,394三角形・157 calls。これは選択した視点の値で、全マップの最大値ではない。中遠景の視錐台除外と建築LODにより150万/250 callsの目安内を確認。

最終の画質切替後、3フレームを待って測定した値（`artifacts/quality-probe.json`）：

| 地点 | 軽量 三角形/calls | 標準 三角形/calls |
|---|---:|---:|
| 麓 | 569,761 / 81 | 1,278,562 / 102 |
| 展望 | 636,871 / 148 | 1,151,394 / 157 |
| 村 | 591,869 / 101 | 1,254,934 / 109 |

本番スモークのあと軽量設定の表示距離と密度を追加調整したため、最終の軽量値は`quality-probe.json`を参照。標準設定・歩行処理はその調整で変更していない。

この環境はGPUを持たずSwiftShaderを使用。描画はおおむね1〜2fps。実GPUの1080p/60fpsを達成したという測定結果ではない。透明な葉のオーバードローと影も実機での計測が必要。

## 制作の残りと制約

建築は独自の手続き的モデル、樹木はEZ Treeの分岐と外部画像。構造や密度・地形を改善したが、AAAの実写風完成品質は未達。正確なスギ・ヒノキ、風化した建築の写真素材、実録ヒグラシ、生活小物と植生の多様化が必要。遠景樹冠は近づいた場合の3D切替が未実装。Unityでの実インポートは未検証。

Three.js約530kB、Rapier compat約2.24MBのchunk警告は残る。音源は53秒の独自合成で、実録ではない。使用素材はMIT/CC0の根拠・原本URL・ハッシュを記録。

GitHub Pagesはmainを公開する。再構築ブランチをpushしても、その段階で公開サイトが切り替わるわけではない。
