# 負荷予算と計測

**計測環境**：このリポジトリの開発環境にはGPUがありません。数値はSwiftShader（CPUでのWebGL2描画）を使い、`window.__satoyama.breakdown()` で集計した三角形数です。fpsは実GPUで計測していないため、60fpsの達成は**未確認**です。

## 2026-11-17：抜本的な軽量化

「めっちゃ重くなってきた」への対応。地図を2.1km四方に広げた（面積約2倍、樹木約12万本）うえで、同じ6か所の名所・標準品質・SwiftShaderで、1フレームに描く三角形とドローコール（主パス＋影のパス）を測り比べた（`renderer.renderBufferDirect` をフックして数えた）。

| 名所 | ドローコール（前→後） | 三角形（前→後） |
|---|---|---|
| 麓の鳥居（foot） | 3,886 → 1,231 | 1,984万 → 887万 |
| 見晴らし（lookout） | 4,575 → 1,454 | 2,010万 → 957万 |
| 田んぼ（paddies） | 3,636 → 1,278 | 1,709万 → 712万 |
| 川（river） | 4,350 → 1,329 | 1,937万 → 937万 |
| 村（village） | 4,213 → 1,342 | 1,741万 → 755万 |
| 沢（sawa） | 2,808 → 1,205 | 1,518万 → 762万 |

ドローコールは約3分の1、三角形は約半分。重さの多くは影のパスだった（前：主パスの3〜4倍のドローコール）。主な変更：

- **影のカスケード**：3段のうち近い1段（約90m）だけがすべての物を描き、遠い2段は木・建物・山だけを描く（`FAR_CASTER` レイヤー）。three.jsは影の物体をカメラのレイヤーで選ぶので、影のパスを包んで遠い段に専用のカメラを渡す（`Lighting.wrapShadowPass`）。影の地図は1フレームに1回だけ描く。
- **建物の影**：模型ごとに、不透明な部品を全部つないだ影専用の代役（位置だけ）を1つ作り、影はそれだけで描く。家1棟は材質ごとに約20部品あり、各部品が影の段ごとに描かれていた。
- **建物の本体**：全模型の全部品を材質ごとに `BatchedMesh` にまとめ、1材質1回のマルチドローで描く（部品ごとの視錐台カリング付き）。以前は模型の部品ごとのInstancedMeshで、村が見える所では300〜540ドローコール。
- **地形**：遠い地形（480m先）は4×4チャンク（150m）を1つのメッシュで描く。遠い影の段の地形は300m四方の粗いタイル（4.7m格子）が代わりに描く。
- **稲**：遠景の稲の面と葉の層は、田全体の外接矩形を覆う1枚の格子（300万三角形）だったのを、稲のある所だけの約110mのタイルにし、カメラ外を捨て、葉の層は170m先で消す。近景の稲の株は面が出てくる約10mまで。
- **下層植生・畑の作物**：地図全体で1つのメッシュ（約92万三角形、遠くまで描いて画素ごとに捨てていた）を96mのタイルに分け、160m（作物は260m）先は描かない。
- **樹木**：遠景の木（ビルボード）を全樹木ぶんの静的なバッファにし、近い木は頂点シェーダーで畳む。以前はカメラが動くたび（運転中は毎フレーム）全樹木をループして約3.6MBを送り直していた。近い木は48mの格子に分け、近くの格子だけを見る。
- **小物（岩・シダ・ヨシなど）**：32mの格子に分け、カメラの近くの格子だけを見る（以前は2m動くたびに全数をループ）。
- **車**：遠景用のLOD2（色を頂点に焼いた1メッシュ・約1,000〜1,750三角形）を足し、12m以内はLOD0、35m以内はLOD1、それより先はLOD2、320m先は描かない。以前は45m先でもLOD1（3.5万〜6万三角形、16〜22ドロー）。
- **解像度の自動調整**：2回続けて45fpsを切ると描画解像度を13%ずつ下げ（設定の0.6倍まで）、57fpsを超える状態が続くと戻す（`?fixedres` で無効）。統計表示に倍率を出す。

実GPUでのfpsは引き続き未計測（このコンテナにはGPUがない）。

## 主な最適化

- **樹木**：約4.1万本を、樹種×変種×LODごとのInstancedMeshで描く。距離・視錐台・影の判定は、カメラが動いたときだけ行う。
- **遠景の樹木**：起動時にLOD0から焼いたビルボード（アルベドと法線のアトラス）で、全樹木を1回の描画で描く。
- **地形**：37.5mのチャンクに分け、3段のLODとスカートで継ぎ目の隙間を隠す。法線は1025²の法線テクスチャで補うので、粗いLODでも陰影は細かい。
- **草・稲**：インスタンス格子をカメラに追従させ、密度0の株は頂点シェーダーで潰す。近景の稲はPoly Havenの写真の草株を稲の高さに拡大したもので、田に近いときだけ描く。中景は基底層と3層のシェル。
- **建築のGLB**：頂点を溶接し、KHR_mesh_quantizationで量子化（24MB→5.7MB）。
- **Poly Havenの小物・植物**：meshoptimizerで削減し、テクスチャを512²にしている。複数の個体が並んだ原本（シダ・低木・雑草・苔むした岩）は1個体ずつに分け、1回の配置で1個体だけを描く。
