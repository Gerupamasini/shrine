# 道路と水田の接続（2026-11）

main 59f1354（PR #13 取り込み済み）から修正。車両モデル・運転機能、旧道、分校、消防詰所を保持する。

## 参考と設計判断

- [林野庁・森林作業道指針](https://www.rinya.maff.go.jp/kinki/seibi/romou_seibi/6_.html)：地形に沿う線形、基本18%以下の縦断勾配、分散排水。実施設計の基準適合を保証するものではない。
- [森林作業道チェックリスト](https://www.rinya.maff.go.jp/j/ken_sidou/forester/attach/pdf/index-72.pdf)：カーブ上部での排水と安全な排水先。
- [千曲市・姨捨の棚田](https://www.city.chikuma.lg.jp/soshiki/rekishibunkazaicenter/rekishi_bunkazai/2/2375.html)：水源から用水、田越し、暗渠排水へ続く水系が景観を支える。
- 前回の丸山千枚田等の参照は `TERRACES_AND_ROUTES.md` に保存。

## 変更

- 山側の経路は角ごとに除外領域を検査して丸める。以前は1か所でも障害物に接触すると経路全体の平滑化を破棄していた。別区間の接続部は前後32mを使う共有曲線に置き換え、約150〜171度の折返しを約4〜7度の連続した方向変化にした。整備された谷底の直線道路は維持する。
- 経路探索の短周期のジグザグを約8mの距離幅で平滑化。共有カーブの高さも周回単位で整合させ、近接した県道・旧道の路肩を相反する高さに固定しない。
- 農道・林道の表示幅を造成幅の3.6mに揃える。森林の2区間に待避用の短い拡幅を設ける。
- 生成済みの沢・用水路の水面と水田境界から、重力で流せる短い給水・田越し・排水接続を生成する。区画IDと給排水先をscene.jsonに保存し、逆流・循環を検査する。開渠は地形を掘り、水面と地図記号を生成。道路横断は暗渠として路面を保持する。
- 給水確認済み126区画、未確認393区画。接続内訳は `scene.json` の `irrigation.links` に保存。これは流量計算ではなく、局所的な高さと距離に基づく接続モデル。
- 屋敷林など、森林マスクの後に追加される樹木も道路から除外する。全樹種の幹と車道の離隔をデータテストで検証する。
- 路面の共通判定を徒歩音・車両物理に使用。砂利と草地のグリップ・転がり抵抗を変える。合成エンジン音と路面別の合成足音を既存のミュートバスへ接続。
- 林内の道路の輪郭を読みやすくする弱い天空補助光を追加。

## 残る問題

- 西側の棚田を含め、全水田への水源と排水先の確定は未完了。未確認区画を黙って給水済みにせず `irrigation.unresolved` に保存している。今後は西側の集水域・取水施設から設計する必要がある。
  - 2026-11-15 追記：川向の棚田には、西沢の取水堰から山腹を等高線沿いに下る川向用水と北の枝線を作った（`TERRAIN_DESIGN.md` の「用水と沢」）。給水確認済みは137区画から249区画に、未確認は365区画から253区画になった（区画数はPR #15・#16の後の生成による）。残る253区画の内訳は、東側の谷底の田が155区画、川向の棚田が57区画（南部が29区画）、その他41区画。接続モデルは水路から14m以内の直接給水と、5m以内・段差2.2m以下の田越しだけを数えるため、水路から離れた田や田越しの条件に合わない田が残っている。
  - 2026-11-15 追記（河岸段丘）：川を一段下げて段丘崖の上下で田を分け、沢の両側6.5mを田から外したため、田は588区画から545区画になった。給水確認済みは229区画、未確認は232区画（割合は前と同じく約半分）。
  - 2026-11-16 追記：中位段丘を加え、沢の両側の空きを4.6mに狭めた後で、田は542区画、給水確認済みは226区画、未確認は236区画。
- 開渠の表現は簡略化されており、流量、漏水、越流、豪雨時の道路排水を扱わない。
- 各田への歩行専用アクセスを明示する道網はまだ追加していない。
- 道路の最小曲線半径の一律保証はなく、通行検証と曲率評価を併用する必要がある。
- 音は実録ではなく合成。エンジン回転数や変速を再現するものではない。

## 通行検証で見つけた不具合と修正

東の林道は短周期のジグザグで車が曲がれず、距離基準の平滑化を追加した。県道と旧道の近接部では、高さを固定する路肩の範囲が重なっていたため、固定する範囲を絞った。修正後の最大局所勾配は東林道約16.5%、北林道約21.6%、県道・旧道との接続を含む宮沢農道約25.2%。18%を全地点で満たす実施設計ではない。

全8区間の車両検査では7区間を通過し、奥沢入口で屋敷林の幹に接触した。森林マスクの後に追加される木も含めて13本を道路から除外した。この修正前後で `scene.json` と `heightmap.r16` は同一であり、通過済み7区間の線形・勾配・構造物は変わっていない。奥沢の再検証は `RURAL_DRIVE_ROAD=okusawa-farm` で実施し、走行・停止を確認した。全区間の最初の記録は `artifacts/terrain/driving-routes.json`、修正後の記録は `artifacts/terrain/driving-recheck.json`。

音はOfflineAudioContextで実際に波形を生成し、足音・エンジン音の出力、空中の無音、共有ミュートの動作を検証する。

地上画像では林道脇の急な切土も見つかったため、林道の外側へ法面を広げて整形した。代表断面の最大局所勾配は6.6から約1.52へ低下。道路中心・既存建物・用水路座標の地表高の変化は0m、道路中心から左右0.7mでの変化は最大約0.000125mで、通行確認した車道を保っている。耕作地の水平面と沢の周囲はこの整形から除外している。

## 検証記録の読み方

- Pythonの経路・区画・給水テスト5件、Nodeのデータ・物理テスト28件、ビルドが成功。
- 本番ビルドで参道・境内・見晴らし、河岸・洗い場・橋、乗降・運転・停止・視点切替・復帰を検証。
- 3周回を徒歩で両方向に連続通行。車両は全8区間を走行・停止確認（奥沢は障害木の修正後に再検証）。
- `artifacts/browser-results.json` は障害木を検出した全体実行の記録で、1件の失敗を含む。修正後の成功記録は `artifacts/terrain/browser-recheck.json` と `driving-recheck.json`。失敗を消さず原因と対応を残している。
- 音声テストでは実際の波形出力・空中・ミュートを検証。林道・曲線部は法面整形後の本番ビルドで再撮影し、地上画像を確認した。最終画像テスト1件も成功。

再検証の標準コマンドは `RURAL_DRIVE_ROAD=okusawa-farm CHROMIUM_PATH=/usr/bin/chromium npx playwright test tests/rural-driving.spec.ts`。全区間は `RURAL_DRIVE_ROAD` を指定せず実行する。
