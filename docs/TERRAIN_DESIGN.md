# 地形・配置の設計

実在地のDEMや特定作品の地図をなぞらず、東北の山あいの谷を独自に設計しました。原本は `tools/world/generate_world.py` で、固定シード19940808から決定的に生成します。

## 構図の考え方

1. **夕日を谷へ通す**
   - 18:00の太陽は方位285.6°・高度6.7°です。四方を山で囲むと、村も神社も山の影に入ってしまいます。
   - そこで地図の西側の山を低くしています（`sun_gap`）。地図の外の西北西の鞍部（遠景の山並みの切れ目）は、2026-11-18にユーザーの指示で取り除きました（地図の外は流域全体を浸食モデルで育て、西側も他と同じ山にした）。
   - 太陽が西の山に隠れる時刻は、村から18:01（稜線は西へ約1.6km・高さ約200m）、境内の見晴らしから18:07（約2.0km・約240m）。鞍部があった間は18:22と18:29でした。遠景の地形は影を落とさないので、この後も村は日なたのまま描かれ、太陽の円盤だけが山の陰に入ります。
2. **石段を西から東へ登らせる**
   - 登る間は背後から夕日が差し、杉の幹の影が石段に長く落ちます。
   - 頂上で振り返ると、南西の眼下に村と田が広がり、右手に夕日が来ます。順光でも逆光でもなく、斜光で村を見下ろす配置です。
3. **神社の尾根**：東の山から張り出した尾根の先端に境内（標高42.0m）を造成しています。南西の縁は高さ4mの石垣で、その外側は急斜面です。見通しの扇形（±38°・190m）では、樹冠が見下ろす視線（俯角13°）より下に収まる低い雑木と下層植生だけを置き、斜面が芝生のように裸にならないようにしています。

## 大地形（浸食モデル）

山と谷は `tools/world/region.py` の地形発達モデルで作ります。ノイズで山を「描く」のをやめた理由は、ノイズには水系（沢が合流して本流へ下る構造）がなく、上から見ても横から見ても塊にしか見えなかったためです。

| 要素 | 内容 |
|---|---|
| 範囲と格子 | 地図を中心に4.8km四方、769²（6.25m間隔）。地図（2.1km）にはこれを双三次補間して使い、6m格子で表せない小さな起伏（16m周期、±0.5m）を足す |
| 手順 | 各セルが最も低い隣へ流れるとして集水面積を求め、ストリームパワー則（浸食量 ∝ 面積^0.45 × 勾配）で下刻する。陰解法なので大きな時間刻みでも安定。毎回、隆起を足し、土壌クリープ（ガウスぼかし）で尾根を丸め、安息角を超えた斜面を崩す。240回で、隆起と浸食がほぼ釣り合う |
| 計算 | 集水面積と陰解法の浸食は、流路の木に沿ったポインタ倍化で解く（numpyのみ、769²で1回0.15秒ほど）。全体で約35秒。結果は入力のハッシュをキーに `.cache/` へ保存 |
| 隆起の分布 | `mountains0()` が隆起の強さの分布を与える（山を高くしたい所、低く保ちたい所）。高さそのものではない |
| 固定する面 | 谷底（水が出ていく基準面）。川向の斜面と神社の尾根は「手で設計した面」として高さを保ち、水は通す。境目は帯状にぼかして折れ目をなくす |
| 谷底の幅 | 集水面積が3ha以上の沢は、側方へ削って平らな谷底を作る（半幅 ≈ 0.05×√面積、最大40m）。集水面積が60ha以上の支谷だけ棚田にする |
| 沢の流路 | モデルの流路（集水面積の大きい順）から、河口が県道の東にある2本を選び、なめらかにして地図の沢にする |
| 谷の形 | `VALLEY` の制御点（z、谷底の中心x、谷底の半幅）を補間。本流は西の山裾、県道は東の山裾に沿う |
| 地図の外 | 上沢川の流域全体（14km四方）を同じ浸食で育てる（下の「地図の外：上沢川の流域」） |

## 地図の外：上沢川の流域

地図の外は `tools/world/beyond.py` で、上沢川の流域全体を14km四方にわたって同じ浸食モデルで育てます（2026-11-18）。以前は地図の周囲1.6kmだけが浸食モデルで、その先はノイズの山並みでした。そのため遠景に水系がなく、川の谷は周りの地形の端（地図の外1.35km）で高さ約250mの壁に突き当たっていました。

| 要素 | 内容 |
|---|---|
| 範囲と格子 | 16.4km四方、1025²（16m間隔）。外周は14kmの図の外へ1.2kmはみ出させ、計算の端が図に出ないようにする |
| 固定する面 | 地図（書き出した高さそのもの）と、地図の外側200mの帯（region.pyの山。地図の端を横切る尾根と沢がそのまま外へ続く。西側だけは帯を15mにして、旧モデルの鞍部を残さない）。上沢川の谷底は、北は地図の中心から2.3km先の三つの谷の分かれ目まで、南は蛇行する峡谷として図の端まで設計して固定する（谷底の高さは地図の勾配の続き、南は0.42%で下る）。外周は隣の流域の高さ（約400m）に固定し、そこから外へ流れ出る沢もある |
| 初期形状 | 川から離れるほど上がる面と、地図とその帯の縁の高さから外へ上がる面の高い方（帯の周りに溝ができ、帯に沿った沢になるのを防ぐ）。支流の筋（`SEEDS`：地図の奥沢・宮沢の谷の延長、両岸から約1kmおきに下流へ斜めに合流する支流、分かれ目から北・北西・北東へ広がる源流）を、ノイズで揺らして掘り下げておく |
| 隆起 | 川と地図の近くは地図の山と同じ強さ、外ほど弱め（谷が長いので弱めないと外周が高くなりすぎる）、北をやや強く、南をやや弱く。北西と南西の山頂（`HIGHS`）に集中させる |
| 浸食 | region.pyと同じストリームパワー則（k=0.2、m=0.45）、隆起3.8m/回、クリープ12m、安息角0.95、560回。20回ごとに窪地を埋め直す（クリープと崩落で窪地ができ、水を飲み込んだまま隆起で持ち上がり続けるため）。約3分。結果は入力のハッシュをキーに `.cache/` へ保存 |
| 書き出し | `far-heightmap.png`：14km四方、769²（18.2m間隔）、−60〜1000m。実行時は1つおきの頂点（36m）でメッシュにする（`meshStride`）。`mid-heightmap.png`：地図の周囲4.8km、769²（6.25m）。地図の際（帯の内側）はregion.pyの6.25mの山そのもの、その外は流域の計算から。地図の中は地図の高さ。川の溝（低い段丘面と崖）は地図の外へ続き、4.8kmの端の手前で谷底の高さへ戻る |
| 結果 | 北西の山が約870m、南西の山が約780m。地図の周り（地図の外〜2.4km）の稜線は200〜300m、2.4〜4kmで300m前後、外周で400〜600m。上沢川は図の南端で約−30m |

## 川

東北の谷あいの農村を流れる、普通河川クラスの小さな川を想定しています。集落の中心（堰と橋のある区間）だけが河川改修で直線化・護岸化され、その上流と下流は自然の流路を残している、という1990年代前半にありそうな姿にしました。

| 要素 | 内容 |
|---|---|
| 区間 | 改修区間（z=−50〜226m、堰・橋・落差工2か所）は直線で両岸ともコンクリートブロック（間知ブロック）の護岸。上流と下流は自然の流路で、谷底を蛇行する（波長約280m、振れ幅±10.5m。北の峡谷と南端では振れを小さくする） |
| 河道 | 自然区間は河床幅12〜19m（湾曲の頂部で広い）、改修区間は10〜14.6m。河道の中に低水路と砂州・草の生えた高い州があり、増水時はここまで水が広がる |
| 低水路 | 水面幅4.3〜6.9m（場所によって広狭がある）。自然区間では湾曲の外側に寄って淵（最深0.8m、深みは外岸側）を作り、湾曲と湾曲の間を瀬（水深0.1〜0.25m、幅が24%広い）で渡る。改修区間は交互砂州の間を流れる |
| 水面の縦断 | 自然区間は谷の勾配（0.58%）に沿い、瀬で急に・淵でほぼ水平に下る（瀬と淵が湾曲ごとに交互に来る）。改修区間は落差工の間を1/670で下り、堰の上流135mは湛水 |
| 岸 | 自然区間は土の岸。湾曲の外側は1:0.9の削れた岸、内側は1:2.3のなだらかな岸と砂州。古い空石積みの護岸は、田に迫る湾曲の外側と集落の洗い場（z=−247m・288m）だけにあり、一部は崩れて途切れている。川向の棚田の足元に迫る西岸の湾曲にも、途切れた石積みがある。改修区間の下流端の西岸に間知石の護岸 |
| 河床の物 | 削れた岸の根元と瀬に転石（巨石）、湾曲内側の砂州に流木、水際に川石、砂州にツルヨシ、高い州に柳の低木と草 |
| 固定堰 | z=92m、落差約0.55m。上流135mが湛水区間（護岸から護岸まで水面）。下流側は斜面＋水叩き5m＋端部の小段 |
| 取水口・用水路（堰） | 堰の6m上流の東岸に取水口（門柱、朱の錆止め塗装のスルースゲート、巻上げ機）。そこから幅1.2mのコンクリートU字溝が、蛇行する川から離れた直線に近い線で田の縁を南へ下る（1/1000）。川より緩いので下流ほど田に近づき、川沿いの低い田に水を配る |
| 落差工 | 改修区間の2か所（z=178m・222m）。コンクリートの床止め＋水叩き3.2m、下流に護床の巨石 |
| 洗い場 | 東岸の2か所。古い石積みの護岸を切って8段の石段を下ろし、下に洗い石を置く |
| 橋 | z=140mで農道が渡る。床版橋（幅3.2m）、中央に流れ向きの橋脚、低い高欄、親柱と銘板 |

1.17m間隔の高さ場では1:0.4の護岸を表せません。石積みの護岸と天端の下は地形を見えない高さまで下げ、`architecture/river-works.glb`（護岸・天端・落差工・堰・取水口・用水路・洗い場）を閉じた形でかぶせます。古い空石積みの天端はコンクリートではなく苔むした石の笠石です。歩行判定は、護岸に沿った箱コライダー（天端の高さ）で補います。土の岸はふつうの地形です。

水面は河床の中心に沿ったX方向の断面の帯で、岸から岸まで張ります。水際は形状で作らず、ピクセルごとに高さ場から河床の高さを読み、水面より高い所を描かないことで、砂州との境目を地形と一致させています。地図には、濡れている低水路だけを水色で描き、護岸は護岸のある所だけ線で描きます。

## 河岸段丘

川は谷底を一段掘り下げ、自分の氾濫原の上を流れています。田の並ぶ谷底（高い段丘面）と川のあいだに、低い段丘面と段丘崖があります。

| 要素 | 内容 |
|---|---|
| 下がり | 川の水面・河床・岸・護岸・堰・橋・堤防道・堰の用水路は、すべて元の設計より4.7〜5.9m低い（`river_drop(z)`。長い波長の2つの正弦波で谷に沿ってゆっくり変わる。2〜3mでは田から見て草の土手にしか見えなかったので、2階建ての家ほどの段にした）。下がりの変わり方は谷の勾配より小さく抑えているので、川の水面は下流へ単調に下ったまま。岸の天端（低い段丘面）は水面の約1.9m上、田の並ぶ谷底はそのさらに4〜6m上。地図の外へも川の谷（低い段丘面の高さの溝と崖）は続き、地図の端で谷底の壁に突き当たらない（周りの地形 `mid-heightmap.png`） |
| 段丘崖 | 崖の足の線は、蛇行帯の外縁（河床・岸・堤防道の外端を1.5湾曲ぶんの幅で包んだ線）に、谷に沿って変わる幅（東2〜26m、西1.5〜12m）を足したもの。湾曲の外側が崖に寄る所もあれば、広い氾濫原を残す所もある。堰から下流の東側は、堰の用水路の東に低い田を置ける幅を取る。崖の面は約37°（1:1.33）で、崖の線は小さく揺らぐ。西は川向の扇状地の裾と山裾を切る |
| 低い段丘面 | 岸の天端より0.1m低く、岸から離れるほど0.35m下がる（自然堤防と後背の湿地）。昔のままの小区画の田（堰の用水路の水を受ける）、柳の低木、ススキ |
| 中位の段丘面 | 低い段丘面が広い所（東12m以上・西7m以上）では、その山側の一部が1.45〜2.15m高い平らな段として残り、自分の崖（同じ約37°）で低い段丘面へ下りる。谷に沿って出たり消えたりする（2つの正弦波で決める）。今の地形では東岸に計約490m。西岸は氾濫原が狭く、中位の段はない |
| 崖の面 | 田も家も置かない（崖の上下2.2〜2.4mも空ける）。広葉樹・欅・ときどき杉の林が途切れ途切れに並び、竹の群れ、間に草と低木 |
| 崖を越える道 | 橋から町道へ上る道、谷の中央の農道から堤防道へ下りる枝道は、勾配8〜10%以下の坂で崖を斜めに上り下りする（崖の肩を切り、崖の下に盛る）。崖の近くの枝道の分かれには、短い水平の踊り場を取る。谷の中央を南北に通る農道は、崖の足から30m以上離す |
| 地図 | 段丘崖を土がけの記号（茶の線と、低い側への短いひげ。主の崖は太く、中位の崖は細く）で描く。`scene.json` の `terrace.scarps` は各崖の中ほどの線（`level` は `main`・`middle`）、`terrace.drop` は下がりの範囲 `[最小, 最大]` |

## 用水と沢

谷底は川から県道へ向かって高くなり、川は谷底より一段低い氾濫原を流れているので、川から取った水は氾濫原の低い田にしか届きません。高い谷底の田には、山の沢から水を引きます。

| 要素 | 内容 |
|---|---|
| 取水堰（沢） | 奥沢・宮沢それぞれの谷を少し登った所に、沢をせき止める低いコンクリートの堰と、用水路の口の鋼製ゲート |
| 幹線用水路 | 幅0.9m・深さ0.5mのコンクリートU字溝。取水堰から谷を下って県道の手前に来て、管で県道の下をくぐり、県道の盛土の足元（田の高い側の縁）を下流へ流れる。水面は、それが潤す田（西へ6〜12m）より0.12m以上高く、下流ほど低い。地面が下流で高くなる所では、上流側を低い土手に載せて水位を保つ。私道・農道・参道が横切る所は蓋掛け |
| 支線水路 | 幅0.6mの三面張りの水路。幹線用水路から田の間を下って、川（土手の下は蓋掛け、護岸か土の岸に吐き口）か、堰の用水路へ落ちる。用水と排水を兼ねる。北の系統は5本、南の系統は4本。河床は田面の0.42m下を田に沿ってゆるく下り、谷底の少し急な所は高さ0.6m以下の落差工（コンクリートの落ち込み）で下りる。段丘崖（落差3〜6.3m）は1本の斜めの急流工（コンクリートの斜路。勾配1:2〜1:2.7、崖の肩を切って作る）で下り、足もとは水叩きの桝。川の岸では、護岸なら護岸に開けた箱型の吐口から落とし込み、土の岸なら岸を下り、その下の河原（水面より0.6〜1m高い州）を横切るコンクリートの斜路で水際まで下る（`channel.outlet`。側壁の天端は地面に沿う）。堰の用水路へ落ちる1本は、そのまま用水路に入る |
| 沢 | 奥沢・宮沢。山の谷の中は渓流：狭い石の河床が谷底に切れ込み、急な所ほど深く（0.6〜1.4m）、岸は岩が出る急な斜面。河床は一様な坂ではなく、平らな瀬と、巨石の落ち口（高さ0.3〜0.95m）の下の淵（滝壺）の繰り返し（ステップ・プール）。森の中の最も急な所に砂防えん堤（高さ約2m。水通しの切欠き、両岸へ入る袖、水叩きと側壁、端の小段）。取水堰の上は湛水し、水は堰を越えて落ちる。小さい奥沢は県道の下を箱型の暗渠（面壁・翼壁・白いガードパイプ）でくぐり、大きい宮沢は県道の短い橋（斜橋。床版、低いコンクリートの高欄、親柱と銘板）の下をくぐる。田の中は幅1.5mの三面張り水路で、谷底では田面の0.95m下をゆるく下り、段丘崖は1本の急流工（奥沢5.0m・宮沢5.6m）で下りる。農道と土手の下は蓋掛け。宮沢は改修区間の護岸の吐口から川へ落ち、奥沢は土の岸と河原を横切る斜路で水際まで下る。山の中の落ち口は高さ場でも切り立つ（河床を折れ点で補間し、1m余りの坂にならない） |
| 西沢 | 川向の北の支谷を下る西側の沢。奥沢・宮沢と同じ渓流（ステップ・プールと砂防えん堤）で、扇状地の裾の急な所は滝の連なりになる。川に出る所は改修区間のブロック護岸なので、氾濫原を護岸まで来て、護岸に開けた箱型の吐口から1m余り落ちて川に注ぐ（落とし込み。下に捨て石）。土の岸なら岸を刻んで最後の段で川へ落ちる |
| 沢の岩 | 落ち口ごとに2〜4個の巨石が並んで段を作る（水はその間と上を越える）。急な所ほど河床と岸に転石が多く、岸の上には苔むした岩。砂防えん堤の下と沢の出口には捨て石。急な岸の地肌は岩（苔むした岩のテクスチャ） |
| 川向用水 | 西沢の取水堰（z≈−159）から、山腹の等高線に沿って約440m下る幅0.9mのU字溝（1/320）。経路は、地面が水面より少し高い（浅い切土になる）所ほど安い経路探索で決めるので、支谷に入っては出る。盛土は切土より高くつけ、沢と家は避ける。棚田の上端（北西の角）で分水桝に入り、本線は棚田の最上段より上を南へ（z≈422まで）、北の枝線（約114m）は棚田の北の先端へ急に下る。その下の段は田越しで水を受ける |
| 用水路の開口 | 幅0.9mの水路は地形の格子（1.17m）より細いので、高さ場を掘ると斜めの区間で壁の横にのこぎり状のくぼみができる。そこで地面は水路の上で壁の天端の高さに閉じ、地形シェーダーが `channels.png`（0.5m格子の、開いた水路の中心線までの距離）を読んで、壁の内側だけ地面を描かない。水路の山側は幅2.2mの平らな管理用の段、谷側は1:1.5の盛土（U字溝の外側が少し見える）。田の中の三面張り水路（幅1.5m）と支線水路（幅0.6m）も同じ方法で開ける（以前は高さ場を掘っていたため、1列か0列のぎざぎざの溝になっていた）。`channels.png` の距離は水路ごとに内幅で割り戻してあるので、一つのしきい値で各水路がその内幅だけ開く |
| 田への取り入れ口 | 水源（沢・水路）から田の縁への短い水路（`irrigation.links`）は、地面の中を通る区間だけを細い水路として描く。沢の谷の上を横切る部分は描かず、残りが1m未満なら管とみなして描かない。幹線用水路は取水堰を出るとすぐ沢の脇（約4m）へ離れて下る |
| 急な地面のテクスチャ | 崖・切土・沢の岸のような約35°より急な地面は、真上からの投影に加えて横からも投影して貼る（真上からだけだと、45°を超える面でテクスチャが伸びて平たい帯に見えた） |

## 集落

東北の谷あいの農村の構成を参考にしました。

- **商店や公共施設の位置**：農村の研究では、雑貨店・農業倉庫・集会所・神社は集落の中心に、郵便局・駐在所・専門の商店は幹線道路沿いに集まるとされています。
- **家の構え**：道に面した家は道に向けて建ち、離れた農家は南向きにして北西に屋敷林を持ちます。宮城では、屋敷林は居久根（いぐね）と呼ばれ、冬の北西風を防ぐため屋敷の北側と西側に杉などを植えます。
- **道の舗装**：県道はほぼ舗装されていますが、農道の舗装率は今でも4割弱です。

| 要素 | 内容 |
|---|---|
| 中心（町場） | 町道（橋へ向かう道）が県道に出る辺り、z=50〜186mの県道の両側。店や家が間口を道に向けて詰めて並ぶ。商店（よろず屋）、酒屋（たばこ）、豆腐屋、理容店、郵便局、駐在所（赤色灯）、農協の支所と農業倉庫、地区公民館、火の見櫓と消防の器具置場。店は2階建ての平入りで、1階はアルミのガラス戸かシャッター、トタンの庇と看板、2階が住まい。側溝はコンクリート蓋で覆い、側溝から店先まではコンクリート舗装（車道のアスファルトより明るい）。丸ポスト・電話ボックス・自動販売機・バス停がある |

## 品質の検証

`npm test`（`tests/world.test.mjs`）で次を確認しています。

- 高さマップの形式
- 石段の段数・寸法・踊り場
- 境内と村の高低差（30〜50m）
- 川の水面が下流へ単調に下ること、落差工と堰が改修区間だけにあり段差があること、自然区間の水面幅（3.5〜10m）・淵の深さ（0.45〜1.0m）・瀬（0.3m以下）、河床幅、岸の高さ、改修区間が両岸ブロック護岸で、それ以外の岸の6割以上が土の岸であること、古い石積みが東岸の4区間以上と西岸にあること、蛇行の振れ幅
- 用水路が堰の湛水から取水され、堰より下流では川の水面より高いこと
- 沢から取水する幹線用水路が2本あり、下流へ単調に下り、県道の下を管でくぐり、沿った田より高い水位で流れること。支線水路が5本以上あり、川へ向かって下ること
- 川向用水が西沢から取水し、下流へ単調に下ること。取水堰からの区間の85%以上で脇の地面が水面−0.3mより高い（土手に載らず山腹を通る）こと。棚田沿いと北の枝線では85%以上で東8mの段より水面が高いこと。枝線は本線の分水桝から本線より低い水位で出ること。どの用水路にも取水堰か、取水堰のある本線があること
- 大きい沢が県道の橋の下を、小さい沢が暗渠をくぐること
- 水田内部の水平
- 18:00の太陽が地平線より上にあること
