# 地形・配置の設計

実在地のDEMや特定作品の地図をなぞらず、東北の山あいの谷を独自に設計しました。原本は `tools/world/generate_world.py` で、固定シード19940808から決定的に生成します。

## 構図の考え方

1. **夕日を谷へ通す**
   - 18:00の太陽は方位285.6°・高度6.7°です。四方を山で囲むと、村も神社も山の影に入ってしまいます。
   - そこで西北西に鞍部（`sun_gap`）を開け、遠景の山並みにも同じ方位の切れ目を作りました。
   - その結果、太陽方向の地平線の仰角は、村から約3.5°、境内から約0°です。18:15頃に村が先に山影へ入り、境内にはまだ夕日が残ります。
2. **石段を西から東へ登らせる**
   - 登る間は背後から夕日が差し、杉の幹の影が石段に長く落ちます。
   - 頂上で振り返ると、南西の眼下に村と田が広がり、右手に夕日が来ます。順光でも逆光でもなく、斜光で村を見下ろす配置です。
3. **神社の尾根**：東の山から張り出した尾根の先端に境内（標高42.0m）を造成しています。南西の縁は高さ4mの石垣で、その外側は急斜面です。見通しの扇形（±38°・190m）では、樹冠が見下ろす視線（俯角13°）より下に収まる低い雑木と下層植生だけを置き、斜面が芝生のように裸にならないようにしています。

## 大地形（浸食モデル）

山と谷は `tools/world/region.py` の地形発達モデルで作ります。ノイズで山を「描く」のをやめた理由は、ノイズには水系（沢が合流して本流へ下る構造）がなく、上から見ても横から見ても塊にしか見えなかったためです。

| 要素 | 内容 |
|---|---|
| 範囲と格子 | 地図を中心に4.8km四方、769²（6.25m間隔）。地図（1.5km）にはこれを双三次補間して使い、6m格子で表せない小さな起伏（16m周期、±0.5m）を足す |
| 手順 | 各セルが最も低い隣へ流れるとして集水面積を求め、ストリームパワー則（浸食量 ∝ 面積^0.45 × 勾配）で下刻する。陰解法なので大きな時間刻みでも安定。毎回、隆起を足し、土壌クリープ（ガウスぼかし）で尾根を丸め、安息角を超えた斜面を崩す。240回で、隆起と浸食がほぼ釣り合う |
| 計算 | 集水面積と陰解法の浸食は、流路の木に沿ったポインタ倍化で解く（numpyのみ、769²で1回0.15秒ほど）。全体で約35秒。結果は入力のハッシュをキーに `.cache/` へ保存 |
| 隆起の分布 | `mountains0()` が隆起の強さの分布を与える（山を高くしたい所、低く保ちたい所）。高さそのものではない |
| 固定する面 | 谷底（水が出ていく基準面）。川向の斜面と神社の尾根は「手で設計した面」として高さを保ち、水は通す。境目は帯状にぼかして折れ目をなくす |
| 谷底の幅 | 集水面積が3ha以上の沢は、側方へ削って平らな谷底を作る（半幅 ≈ 0.05×√面積、最大40m）。集水面積が60ha以上の支谷だけ棚田にする |
| 沢の流路 | モデルの流路（集水面積の大きい順）から、河口が県道の東にある2本を選び、なめらかにして地図の沢にする |
| 谷の形 | `VALLEY` の制御点（z、谷底の中心x、谷底の半幅）を補間。本流は西の山裾、県道は東の山裾に沿う |
| 地図の外 | 中景（`mid-heightmap.png`、地図の周囲1.6km）は同じモデル。端の600mで遠景の山並み（`far-heightmap.png`）へ混ぜる |

## 川

東北の谷あいの農村を流れる、普通河川クラスの小さな川を想定しています。集落の中心（堰と橋のある区間）だけが河川改修で直線化・護岸化され、その上流と下流は自然の流路を残している、という1990年代前半にありそうな姿にしました。

| 要素 | 内容 |
|---|---|
| 区間 | 改修区間（z=−50〜226m、堰・橋・落差工2か所）は直線で両岸ともコンクリートブロック（間知ブロック）の護岸。上流と下流は自然の流路で、谷底を蛇行する（波長約280m、振れ幅±10.5m。北の峡谷と南端では振れを小さくする） |
| 河道 | 自然区間は河床幅12〜19m（湾曲の頂部で広い）、改修区間は10〜14.6m。河道の中に低水路と砂州・草の生えた高い州があり、増水時はここまで水が広がる |
| 低水路 | 水面幅4.3〜6.9m（場所によって広狭がある）。自然区間では湾曲の外側に寄って淵（最深0.8m、深みは外岸側）を作り、湾曲と湾曲の間を瀬（水深0.1〜0.25m、幅が24%広い）で渡る。改修区間は交互砂州の間を流れる |
| 水面の縦断 | 自然区間は谷の勾配（0.58%）に沿い、瀬で急に・淵でほぼ水平に下る（瀬と淵が湾曲ごとに交互に来る）。改修区間は落差工の間を1/670で下り、堰の上流135mは湛水 |
| 岸 | 自然区間は土の岸。湾曲の外側は1:0.9の削れた岸、内側は1:2.3のなだらかな岸と砂州。古い空石積みの護岸は、田に迫る湾曲の外側と集落の洗い場（z=−247m・288m）だけにあり、一部は崩れて途切れている。川向の棚田の足元に迫る西岸の湾曲にも、途切れた石積みがある。改修区間の下流端の西岸に間知石の護岸 |
| 河床の物 | 削れた岸の根元と瀬に転石（巨石）、湾曲内側の砂州に流木、水際に川石、砂州にツルヨシ、高い州に柳の低木と草 |
| 固定堰 | z=92m、落差約0.55m。上流135mが湛水区間（護岸から護岸まで水面）。下流側は斜面＋水叩き5m＋端部の小段 |
| 取水口・用水路（堰） | 堰の6m上流の東岸に取水口（門柱、朱の錆止め塗装のスルースゲート、巻上げ機）。そこから幅1.2mのコンクリートU字溝が、蛇行する川から離れた直線に近い線で田の縁を南へ下る（1/1000）。川より緩いので下流ほど田に近づき、川沿いの低い田に水を配る |
| 落差工 | 改修区間の2か所（z=178m・222m）。コンクリートの床止め＋水叩き3.2m、下流に護床の巨石 |
| 洗い場 | 東岸の2か所。古い石積みの護岸を切って8段の石段を下ろし、下に洗い石を置く |
| 橋 | z=140mで農道が渡る。床版橋（幅3.2m）、中央に流れ向きの橋脚、低い高欄、親柱と銘板 |

1.17m間隔の高さ場では1:0.4の護岸を表せません。石積みの護岸と天端の下は地形を見えない高さまで下げ、`architecture/river-works.glb`（護岸・天端・落差工・堰・取水口・用水路・洗い場）を閉じた形でかぶせます。古い空石積みの天端はコンクリートではなく苔むした石の笠石です。歩行判定は、護岸に沿った箱コライダー（天端の高さ）で補います。土の岸はふつうの地形です。

水面は河床の中心に沿ったX方向の断面の帯で、岸から岸まで張ります。水際は形状で作らず、ピクセルごとに高さ場から河床の高さを読み、水面より高い所を描かないことで、砂州との境目を地形と一致させています。地図には、濡れている低水路だけを水色で描き、護岸は護岸のある所だけ線で描きます。

## 用水と沢

谷底は川から県道へ向かって高くなり、川の水面は谷底より1.5m低いので、川から取った水は川沿いの低い田にしか届きません。高い側（県道側）の田には、山の沢から水を引きます。

| 要素 | 内容 |
|---|---|
| 取水堰（沢） | 奥沢・宮沢それぞれの谷を少し登った所に、沢をせき止める低いコンクリートの堰と、用水路の口の鋼製ゲート |
| 幹線用水路 | 幅0.9m・深さ0.5mのコンクリートU字溝。取水堰から谷を下って県道の手前に来て、管で県道の下をくぐり、県道の盛土の足元（田の高い側の縁）を下流へ流れる。水面は、それが潤す田（西へ6〜12m）より0.12m以上高く、下流ほど低い。地面が下流で高くなる所では、上流側を低い土手に載せて水位を保つ。私道・農道・参道が横切る所は蓋掛け |
| 支線水路 | 農道の北側に沿う幅0.6mの三面張りの水路。幹線用水路から田の間を下って、川（土手の下は蓋掛け、護岸か土の岸に吐き口）か、堰の用水路へ落ちる。用水と排水を兼ねる。北の系統は5本、南の系統は4本 |
| 沢 | 奥沢・宮沢。谷の中は幅2.6mの石の河床（下流へ単調に下る）。小さい奥沢は県道の下を箱型の暗渠（面壁・翼壁・白いガードパイプ）でくぐり、大きい宮沢は県道の短い橋（斜橋。床版、低いコンクリートの高欄、親柱と銘板）の下をくぐる。田の中は幅1.5mの三面張り水路で、農道と土手の下は蓋掛け。本流の岸に吐き口 |

## 集落

東北の谷あいの農村の構成を参考にしました。

- **商店や公共施設の位置**：農村の研究では、雑貨店・農業倉庫・集会所・神社は集落の中心に、郵便局・駐在所・専門の商店は幹線道路沿いに集まるとされています。
- **家の構え**：道に面した家は道に向けて建ち、離れた農家は南向きにして北西に屋敷林を持ちます。宮城では、屋敷林は居久根（いぐね）と呼ばれ、冬の北西風を防ぐため屋敷の北側と西側に杉などを植えます。
- **道の舗装**：県道はほぼ舗装されていますが、農道の舗装率は今でも4割弱です。

| 要素 | 内容 |
|---|---|
| 中心（町場） | 町道（橋へ向かう道）が県道に出る辺り、z=50〜186mの県道の両側。店や家が間口を道に向けて詰めて並ぶ。商店（よろず屋）、酒屋（たばこ）、豆腐屋、理容店、郵便局、駐在所（赤色灯）、農協の支所と農業倉庫、地区公民館、火の見櫓と消防の器具置場。店は2階建ての平入りで、1階はアルミのガラス戸かシャッター、トタンの庇と看板、2階が住まい。側溝はコンクリート蓋で覆い、側溝から店先まではコンクリート舗装（車道のアスファルトより明るい）。丸ポスト・電話ボックス・自動販売機・バス停がある |
| 集落 | 東の山裾の県道沿い。町場の南北に中里・宮下・下宿・南沢（8〜14軒）が続き、北の沢の出口に奥沢（5軒）が離れてある。道沿いの家の約8割は町場の中心から330m以内。道から12〜16mの家は道に向けて建ち、屋敷林を持たない（裏に庭木が1〜2本）。奥の家は南向きで、北と西に居久根。集落ごとに成り立ちを変えている：中里は古い農家集落（茅葺きと蔵の大きな農家が道から離れて南を向く。道に面する家は2割）、宮下は神社の下の集落で、参道の分かれ道に集会所がある、下宿は旧道沿いの家並み（県道のバイパスから外れた幅4mの旧道に、瓦の家と消防団詰所が両側から面して詰まって並ぶ）、南沢は新しい家と農家が混ざる（トタン屋根が多く、ブロック塀が多い） |
| 川向・散居 | 川向は棚田の集落。家を田の中に散らさず、斜面の中ほど（川から約165m、谷底から約17m上）を等高線沿いに通る道に並べる。道は幅約42mの平らな段（古い河岸段丘を広げた平場）の上を通り、その山側は短い急な崖で斜面に戻る。家は道の山側が多く、それぞれ石垣の上の平場に建ち、谷（東）を向く。橋の西詰からこの道へ、町道が斜めに登る。谷の中央を通る農道の脇に、居久根に囲まれた散居の農家6軒 |
| 寺・墓地・診療所 | 南の集落の共同墓地は、南沢の上の山裾を切った小さな平場（約18×13m）にあり、墓が3列で谷を向く。県道から小道が登り、裏に杉と檜。寺（瑞雲寺）は中里と宮下の間、東の山裾を切った平場にある。本堂が谷を向き、山門・鐘楼・六地蔵、北側に墓地、裏と北に杉。県道から砂利の参道が登る。診療所は村の南端、県道の東側に前庭を取って建つ |
| 敷地 | 農家は母屋の前に土の庭（道に向いた家は道の路肩まで）。道から遠い側に庭へ口を向けた納屋、その奥の母屋の裏手の角に作業小屋（農家の75%）、反対側に家庭菜園（道に面した家では母屋の脇まで）、庭の物干し台、庭の隅に柿の木。母屋の脇にはプロパンガスのボンベ2本と灯油のホームタンク。町場の家と店は敷地が狭く、納屋や菜園はない |

| 地盤 | 集落は谷底+1.25m、川向は+1.6m。山側では最大4m切り込んで平らにし、前の地面より1.1m以上高い所は石垣にする。散居の農家は周りの田より0.7m高い屋敷地に建てる。町場は道路より0.18m高い |

## 植生の配置規則

| 区域 | 内容 |
|---|---|
| 参道 | 杉（82%）と檜の高木を4〜7.5m間隔で、石段の両側2列に置く |

| 御神木 | 1本（スケール1.75）に注連縄 |
| 山林 | 約120m間隔の種点で林を林分に分ける。植林地（杉・檜）は林分ごとの向きの格子に1本ずつ、樹齢をそろえて植える（列が見える）。植林して数年の若い林（樹高が成木の約1/3）、伐採跡（切り株・低木・倒木、森の密度を下げて草地にする）を所々に置く。自然林（広葉樹、欅、尾根に赤松）は群生と空き地を作り、大きさをばらつかせる。林縁は低い木と低木 |

## 品質の検証

`npm test`（`tests/world.test.mjs`）で次を確認しています。

- 高さマップの形式
- 石段の段数・寸法・踊り場
- 境内と村の高低差（30〜50m）
- 川の水面が下流へ単調に下ること、落差工と堰が改修区間だけにあり段差があること、自然区間の水面幅（3.5〜10m）・淵の深さ（0.45〜1.0m）・瀬（0.3m以下）、河床幅、岸の高さ、改修区間が両岸ブロック護岸で、それ以外の岸の6割以上が土の岸であること、古い石積みが東岸の4区間以上と西岸にあること、蛇行の振れ幅
- 用水路が堰の湛水から取水され、堰より下流では川の水面より高いこと
- 沢から取水する幹線用水路が2本あり、下流へ単調に下り、県道の下を管でくぐり、沿った田より高い水位で流れること。支線水路が5本以上あり、川へ向かって下ること
- 大きい沢が県道の橋の下を、小さい沢が暗渠をくぐること
- 水田内部の水平
- 18:00の太陽が地平線より上にあること
- 棚田が水平な段になっていて、谷底から8m以上登ること、耕作放棄の段があること
- 町場に商店・郵便局・駐在所・農協・公民館がそろい、道に面した建物が道を向いていること
- 奥の農家が南向き（±25°）で、納屋と短い私道（75m未満）があり、85%以上に北か西の居久根があること
- 県道が幅6m以上の舗装で、砂利の農道があること
- 道の横断面（車道・路肩・側溝の縁）が水平で、道沿いの法面が1:0.8より急でないこと（石垣のある屋敷の前を除く）。県道がトンネルの坑門から始まること
- 地図の画像と、地区・集落・施設の名前がそろっていること
- 山に沢と尾根の起伏があること、本流が蛇行すること、沢が下流へ単調に下り県道の下をくぐること、寺と診療所があること、道沿いの建物が中心地に集まっていること
- 全配置がGLBに解決し、全材質がテクスチャに解決すること
- 石段の上に木がないこと
- 録音のライセンスが記録されていること
