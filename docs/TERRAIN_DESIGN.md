# 地形・配置の設計

実在地のDEMや特定作品の地図をなぞらず、東北の山あいの谷を独自に設計しました。原本は `tools/world/generate_world.py` で、固定シード19940808から決定的に生成します。

## 構図の考え方

1. **夕日を谷へ通す**
   - 18:00の太陽は方位285.6°・高度6.7°です。四方を山で囲むと、村も神社も山の影に入ってしまいます。
   - そこで西北西に鞍部（`sun_gap`）を開け、遠景の山並みにも同じ方位の切れ目を作りました。
   - その結果、太陽方向の地平線の仰角は、村から約3.5°、境内から約0°です。18:15頃に村が先に山影へ入り、境内にはまだ夕日が残ります。
2. **石段を西から東へ登らせる**
   - 登る間は背後から夕日が差し、杉の幹の影が石段に長く落ちます。
   - 頂上で振り返ると、南西の眼下に村と田が広がり、右手に夕日が来ます。順光でも逆光でもなく、斜光で村を見下ろす配置です。
3. **神社の尾根**：東の山から張り出した尾根の先端に境内（標高42.0m）を造成しています。南西の縁は高さ4mの石垣で、その外側を急斜面とし、木を除いて眺望を確保しています（見通しの扇形の範囲には樹冠を置きません）。

## 主な寸法

| 要素 | 値 |
|---|---|
| 範囲 | 1200m四方。1025²、16-bit（量子化の1段は6.4mm）。高さ範囲は−20〜400m |
| 谷底 | 標高2〜9m。南へ0.58%下がる。谷の中心線は蛇行し、半幅は約255m |
| 石段 | x=124.0〜202.5m、z=−40m。蹴上げ0.175m・踏面0.34m（2R+T=0.69m）、幅5.2m |
| 石段の脇 | 堤が石段より0.25m高く、外へ0.42の勾配で上がり、尾根に接続する |
| 境内 | x=202.5〜270m、z=−82〜−2m、y=42.0m。床は全面砂利。拝殿・本殿・賽銭箱・狛犬・灯籠は石段と参道の軸（z=−40m）に揃える |
| 川 | 水面は谷底の1.45m下で、一方向に下る。幅4.6±1.0m。河床は中央が深い |
| 道 | 幅4mの舗装路が谷の東寄りを通り、宅地より低い盛土の上にある。両側に土の路肩とコンクリートの側溝（中心から2.45m、幅0.45m・深さ0.42m）がある。分岐の未舗装路が麓の鳥居へ上る（参詣道。木・竹・下草・家を置かない） |
| 宅地 | 8つの集落に73軒。道から13〜62m離し（家どうしは22m以上）、地盤は谷底から+1.25m（丘の側へは最大+2.6m）。参詣道の分岐の両側18m以内には建てない |
| 水田 | 谷を横切る帯（幅24〜42m）を、谷に沿って26〜58mごとに区切った不整形の区画。区画ごとに田面を水平にし、境界には+0.32mの畦を置く |
| 畑・休耕地 | 宅地から75m以内の区画の35%を畑、全体の7%を休耕地にする |
| 法面 | 田の周囲は最大35°の勾配で地形に接続する |

## 植生の配置規則

| 区域 | 内容 |
|---|---|
| 参道 | 杉（82%）と檜の高木を4〜7.5m間隔で、石段の両側2列に置く |
| 境内の周囲 | 杉・檜・欅・広葉樹 |
| 御神木 | 1本（スケール1.75）に注連縄 |
| 山林 | 5.3mの格子に揺らぎを加え、森の密度マスクで間引く |
| 山林の樹種 | ノイズで分けた植林地は杉・檜、尾根・高所は赤松、それ以外は広葉樹 |
| 集落の背後 | 竹林を16か所 |
| 宅地 | 屋敷林と庭木 |
| 川沿い | 低めの広葉樹 |
| 下草 | 歩ける範囲だけに、シダ・低木・雑草・苔むした岩・切り株・倒木を置く。石段の縁は特にシダと岩を密にする |
| 草・稲 | 実行時にGPUで生成し、植生マスクで密度を決める |

## 品質の検証

`npm test`（`tests/world.test.mjs`）で次を確認しています。

- 高さマップの形式
- 石段の段数・寸法・踊り場
- 境内と村の高低差（30〜50m）
- 川の単調な下りと幅
- 水田内部の水平
- 18:00の太陽が地平線より上にあること
- 全配置がGLBに解決し、全材質がテクスチャに解決すること
- 石段の上に木がないこと
- 録音のライセンスが記録されていること
