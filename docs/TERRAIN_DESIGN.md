# 盆地・集落の再設計

遠野のように山に囲まれた農村の土地利用を参考にした独自の盆地。実際の遠野のDEMや道路・家屋をトレースした地図ではない。

1. 南へ約0.3%で下がる広い低地を定義する。川はその低地より低い河床と水面を持ち、上流から下流へ水面高さが一方向に下がる。
2. 水田を56区画の水平な面として造成する。区画境界の2.5mに畦・法面を接続し、水田の中心や内部に山のノイズをかけない。
3. 道路と宅地は自然堤防に相当する高い帯に配置する。18軒の宅地は水田より約1.15m高く、基礎周辺を水平にする。納屋・石垣・進入路は農家に付属する。
4. 西・東・北の山地と南の河川出口を別の地形要素として接続する。山地の大きな尾根に70m/24mスケールの弱い凹凸を足す。地図全域を周期波で上下させない。
5. 神社は標高38mの山裾の高台。麓0mから200段で上る。境内の外縁に造成の法面をつなぎ、村側に見通しを確保する。

## 数値と原本

- 1.2km四方、513²、uint16 LE。量子化の1段は約3.906mm。
- 地形の原本：`tools/generate_world.py`。水田・宅地を先に定義し、その面へ地形を接続した後に建物を配置。
- 原本高度は共通の16-bit RAW/PNG。描画・衝突用は村と川を細かくした同じ非均一格子を使用。地形の見た目と接触面のサンプル間隔を一致させる。
- `scene.json`に水田・家屋・樹木・石段・水面中心線・道路・環境設定、`canopy.json`に遠景樹冠を保存。
- 地形のデータテストで水田内部の高低差3.5cm未満、宅地の基礎支持、河川の単調な下り勾配を確認。

## 植生と見え方

近景は写真の葉の透過画像と分岐メッシュを持つ樹木、山の遠景は同じGLBから焼いた樹冠画像。針葉樹・広葉樹を混ぜ、地面と道・宅地・水田を先に決めて除外領域を作る。遠景画像は近づいて観察するための素材ではなく、山腹を遠くから見るためのもの。

神社の模型や俯瞰ジオラマとして全体を縮めず、建築・段差・樹高・視点をメートルで保持。暖色の直射光、青寄りの空光、距離による霞を分ける。17〜19時は実際の天文計算ではなく美術調整。

## 継続して必要な制作

神社・民家は手続き的に作り直した建築。柱・軒・瓦・壁板・窓・屋根厚を持つが、写真測量や風化の高品質スキャンには及ばない。杉・ヒノキの固有形状、下草の多様化・竹・生活小物、遠景樹冠の近接LOD、実録音源、カスケードシャドウは追加制作が必要。現状をAAA品質の最終風景とは呼ばない。
