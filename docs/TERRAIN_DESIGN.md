# 地形・配置の設計

実在地のDEMや特定作品の地図をなぞらず、東北の山あいの谷を独自に設計しました。原本は `tools/world/generate_world.py` で、固定シード19940808から決定的に生成します。

## 構図の考え方

1. **夕日を谷へ通す**
   - 18:00の太陽は方位285.6°・高度6.7°です。四方を山で囲むと、村も神社も山の影に入ってしまいます。
   - そこで西北西に鞍部（`sun_gap`）を開け、遠景の山並みにも同じ方位の切れ目を作りました。
   - その結果、太陽方向の地平線の仰角は、村から約3.5°、境内から約0°です。18:15頃に村が先に山影へ入り、境内にはまだ夕日が残ります。
2. **石段を西から東へ登らせる**
   - 登る間は背後から夕日が差し、杉の幹の影が石段に長く落ちます。
   - 頂上で振り返ると、南西の眼下に村と田が広がり、右手に夕日が来ます。順光でも逆光でもなく、斜光で村を見下ろす配置です。
3. **神社の尾根**：東の山から張り出した尾根の先端に境内（標高42.0m）を造成しています。南西の縁は高さ4mの石垣で、その外側は急斜面です。見通しの扇形（±38°・190m）では、樹冠が見下ろす視線（俯角13°）より下に収まる低い雑木と下層植生だけを置き、斜面が芝生のように裸にならないようにしています。

## 主な寸法

| 要素 | 値 |
|---|---|
| 範囲 | 1200m四方。1025²、16-bit（量子化の1段は6.4mm）。高さ範囲は−20〜400m |
| 谷底 | 標高2〜9m。南へ0.58%下がる。谷の中心線は蛇行し、半幅は約255m。東の山裾から川へ向けて0.75m下がる（低い扇状地）ので、田は川へ向かって少しずつ段になる |
| 石段 | x=124.0〜202.5m、z=−40m。蹴上げ0.175m・踏面0.34m（2R+T=0.69m）、幅5.2m |
| 石段の脇 | 堤が石段より0.25m高く、外へ0.42の勾配で上がり、尾根に接続する |
| 境内 | x=202.5〜270m、z=−82〜−2m、y=42.0m。床は全面砂利。拝殿・本殿・賽銭箱・狛犬・灯籠は石段と参道の軸（z=−40m）に揃える |
| 川 | 谷の西寄りを流れる小河川。河床幅7〜15m、低水路3〜6m、護岸の高さは水面から1.1〜1.9m。詳しくは下の「川」 |
| 道 | 幅4mの舗装路が谷の東寄りを通り、宅地より低い盛土の上にある。両側に土の路肩とコンクリートの側溝（中心から2.45m、幅0.45m・深さ0.42m）がある。分岐の未舗装路が麓の鳥居へ上る（参詣道。木・竹・下草・家を置かない） |
| 宅地 | 62軒。詳しくは下の「集落」。間口・奥行き・階数・曲り家の翼屋は `tools/architecture/presets.json` を配置・衝突判定・モデル生成で共用する |
| 水田 | 谷を横切る帯（幅24〜42m）を、谷に沿って26〜58mごとに区切った不整形の区画。区画ごとに田面を水平にし、境界には+0.32mの畦を置く |
| 棚田 | 川向の山裾（z=40〜320m）で、谷底からの高さを1.3mごとの等高線の帯に分け、斜面に沿って18〜36mごとに区切る。上端は森に不規則に接する。2割は耕作放棄地で、ススキと雑草が戻っている |
| 畑・休耕地 | 家から60m以内の区画の20%を畑、全体の7%を休耕地にする。畑は畝のテクスチャを世界のX方向に貼り（4.2mで7本、畝の間隔0.6m）、作物の列を畝の頂部（z = 0.6 × (n + 0.4722)）に置く。作物は区画ごとに1種類（ナス・枝豆・里芋・葉物） |
| 法面 | 田の周囲は最大35°の勾配で地形に接続する |

## 川

東北の谷あいの農村を流れる、普通河川クラスの小さな川を想定しています。河川改修の手引きや写真資料（空石積み・間知積みの護岸、頭首工と取水ゲート、交互砂州と瀬・淵、ツルヨシの群落、水害防備林の竹林、洗い場）を参考に、1990年代前半にありそうな姿にしました。

| 要素 | 内容 |
|---|---|
| 横断面 | 河床（砂州＋低水路）→ 護岸（勾配1:0.4、水平0.75m）→ 天端のコンクリート（1.2m）→ 管理用通路（東岸3m、轍の間に草）→ 堤防の法面（1:2）。西の山側が堤防より高い所は1:0.9で切り下げる |
| 護岸 | 上流から順に、土羽（1:1.6の草の法面）、苔むした空石積み（−392〜30m）、堰と橋の区間は間知ブロックの谷積み（30〜212m、テクスチャを45°回転）、下流は間知石積み、最下流はまた土羽。水面付近の0.35mは水に濡れた暗い色にする |
| 低水路 | 幅3.6〜5.6mの流れが、波長約134mで左右に振れる。外側の曲がりは淵（深さ最大0.66m）で護岸の際を流れ、反対側に砂州ができる。流れが岸から岸へ渡る所は瀬で、幅が22%広く浅い |
| 砂州 | 水面から最大0.6m高い。水際は濡れた石（`river_small_rocks`）、その上は乾いた灰色の礫（`ganges_river_pebbles`）、高い所はノイズで草に覆われる |
| 縦断 | 区間内の水面勾配は1/670。82〜118mごとに落差工10か所（0.33〜0.77m。堰の湛水区間の上端だけ0.22m）。区間の中点で水面が谷底−1.45mになるように落差を決めるので、平均の勾配は谷と同じ0.58% |
| 固定堰 | z=92m、落差0.91m。上流135mが湛水区間（護岸から護岸まで水面、深さ0.45〜1.05m）。下流側は斜面＋水叩き5m＋端部の小段 |
| 取水口 | 堰の6m上流の東岸。コンクリートの門柱、鋼製のスルースゲート（朱の錆止め塗装、30cm開）、巻上げ機とハンドル。暗渠で堤防をくぐり、升から用水路へ |
| 用水路 | 幅1.2m・深さ0.42mのコンクリートU字溝（2mごとの継ぎ目）。勾配1/1000で川より緩いので、下流ほど田面に近づく。農道の下は管渠 |
| 落差工 | 堰と同じくX方向に揃えたコンクリートの床止め＋水叩き3.2m。下流に護床の巨石 |
| 洗い場 | 東岸の2か所（z=−247m・288m）。護岸を切って8段の石段を下ろし、下に洗い石を置く。歩行用に約40°の斜面を地形に作る |
| 橋 | z=140mで農道が渡る。床版橋（幅3.2m）、中央に流れ向きの橋脚、低い高欄、親柱と銘板。川に対して9°の斜橋 |

1.17m間隔の高さ場では1:0.4の護岸を表せません。石積みの護岸と天端の下は地形を見えない高さまで下げ、`architecture/river-works.glb`（護岸・天端・落差工・堰・取水口・用水路・洗い場）を閉じた形でかぶせます。歩行判定は、護岸に沿った箱コライダー（天端の高さ）で補います。土羽の区間はふつうの地形です。

水面は河床の中心に沿ったX方向の断面の帯で、護岸から護岸まで張ります。水際は形状で作らず、ピクセルごとに高さ場から河床の高さを読み、水面より高い所を描かないことで、砂州との境目を地形と一致させています。

## 集落

東北の谷あいの農村の家の構え（宮城では屋敷林を居久根と呼び、冬の北西風を防ぐため屋敷の北側と西側に杉などを幾重にも植える）を参考にしました。

| 要素 | 内容 |
|---|---|
| 配置 | 東の山裾の道沿いに6つの集落（上ノ沢・中里・宮下・中村・下宿・南沢、各5〜11軒）。集落の間は田と山林。川向こうの山裾に川向の6軒、谷底の田の中に散居の農家9軒 |
| 向き | すべて南向きで、棟は東西。東の集落は谷側（南南西）へ約7°、川向は南南東へ約16°振る。集落の中では家の向きがほぼ揃う |
| 敷地 | 母屋の南に奥行き11mの土の前庭。道から遠い側の庭の脇に、庭へ口を向けた納屋。反対側に家庭菜園（2〜3種の作物の列）。庭の隅に柿の木 |
| 居久根 | 北側と西側に杉の列（1〜2列、3〜4mおき）、欅と檜を混ぜる。散居の農家は東側も囲み、南だけを開ける。見晴らしからの視線と夕日の方向に当たる所は、視線より低い広葉樹に替える |
| 地盤 | 集落は谷底+1.25m、川向は+1.6m。山側では最大4m切り込んで平らにし、前の地面より1.1m以上高い所は石垣にする。散居の農家は周りの田より0.7m高い屋敷地に建てる |
| 道 | 各家の前庭から道路へ小道（幅2.4m、轍付き）。散居の農家は田の中を道路まで真っすぐ。川向は橋の西詰から登る小道で各家を結ぶ。小道が道路の側溝を渡る所には蓋をかける |
| 共用の施設 | 中村の道路脇に火の見櫓（高さ約12m、半鐘と防災無線のスピーカー）と消防の器具置場。バス停に丸ポスト。各集落の境の道端に石塔 |

## 植生の配置規則

| 区域 | 内容 |
|---|---|
| 参道 | 杉（82%）と檜の高木を4〜7.5m間隔で、石段の両側2列に置く |
| 境内の周囲 | 杉・檜・欅・広葉樹 |
| 御神木 | 1本（スケール1.75）に注連縄 |
| 山林 | 5.3mの格子に揺らぎを加え、森の密度マスクで間引く |
| 山林の樹種 | ノイズで分けた植林地は杉・檜、尾根・高所は赤松、それ以外は広葉樹 |
| 集落の背後 | 竹林を16か所 |
| 宅地 | 居久根（北・西の杉と欅）と庭の柿 |
| 川沿い | 西岸に河畔林（広葉樹・欅・杉。ノイズで群生と切れ目を作り、根元に低木）、中州の高い所に柳の低木、西岸の4か所に竹林（水害防備林）。砂州の水際にツルヨシの群落、土羽の法面と堤防にススキ |
| 下草 | 歩ける範囲だけに、シダ・低木・雑草・苔むした岩・切り株・倒木を置く。石段の縁は特にシダと岩を密にする |
| 草・稲 | 実行時にGPUで生成し、植生マスクで密度を決める |

## 品質の検証

`npm test`（`tests/world.test.mjs`）で次を確認しています。

- 高さマップの形式
- 石段の段数・寸法・踊り場
- 境内と村の高低差（30〜50m）
- 川の水面が下流へ単調に下ること、落差工と堰の段差、低水路の幅（2.5〜7.5m）と湛水区間の幅、護岸の高さ
- 用水路が堰の湛水から取水され、堰より下流では川の水面より高いこと
- 水田内部の水平
- 18:00の太陽が地平線より上にあること
- 棚田が水平な段になっていて、谷底から8m以上登ること、耕作放棄の段があること
- 家がすべて南向き（±25°）で、各家に小道と納屋があり、85%以上の家に北か西の居久根があること、集落が7つ以上に分かれていること
- 全配置がGLBに解決し、全材質がテクスチャに解決すること
- 石段の上に木がないこと
- 録音のライセンスが記録されていること
