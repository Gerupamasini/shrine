# 軽トラの運転

現在のマップに置かれた軽トラ7台を、実車写真を参照した新モデルと運転システムへ置き換えています。駐車位置・向き・台数は維持しています。設定の「近くの軽トラへ移動」から車のそばへ移動できます。

| 操作 | 動作 |
|---|---|
| E | 車のそばで乗車／停車中に降車 |
| W / ↑ | 前進。後退中は制動 |
| S / ↓ | 制動。停止後に後退 |
| A・D / ←・→ | 左右へ操舵 |
| Space | ブレーキ |
| V | 運転席の一人称／車体後方の三人称 |
| マウス | 乗車中の見回し |
| R | 車を元の駐車位置へ戻す |
| Esc / 設定 / M | 設定・地図を開くと運転を一時停止 |

歩行中のWASD・ジャンプ・フリーカメラは従来どおり。乗車中のフリーカメラは無効です。地図や設定から別の場所へ移動すると、車はその場に停車し、徒歩へ戻ります。走行中の降車は制限し、降車先には地面と人が立てる空間があることを確認します。

## 速度計

指定された年代の参考画像を基に、黒い盤面、白緑の目盛り、赤い針、緑灰色の液晶距離計を描画します。軽トラ向けに0〜140km/hの目盛りにしています。針は物理エンジンの実速度に連動し、距離計はそのセッション内の実走行距離を積算します。復帰操作による移動は距離へ加えません。ページを読み直すと距離はリセットされます。

運転中は右下の計器と小さなV/E案内を表示し、長い操作説明は設定へ移しています。架空のエンジン回転数・燃料値は表示していません。

## 実装

- `src/vehicles/simulation.ts`：Rapierの動的車体、質量・慣性、四輪の接地レイ、スプリング、駆動力、操舵、制動。
- `src/vehicles/fleet.ts`：モデルの読み込みとLOD、車輪・ハンドルの描画、乗降、三人称カメラの障害物回避。
- `src/vehicles/hud.ts`：SVGのアナログ計器と距離計。
- `src/vehicles/specs.ts`：モデル原稿の寸法を共用。模型と車軸・カメラ・衝突形状のずれを抑える。
- `src/main.ts`：60Hz固定ステップで徒歩／運転を切り替え、キー入力とポーズを共通管理。

車体は地形・建物・壁・木と同じRapierワールドで衝突します。乗車中は歩行者のカプセルを無効にし、降車時に戻します。高速時の舵角を抑え、前進は約60km/h、後退は約15km/hを上限としています。手動変速、交通AI、エンジン音、車両位置の永続保存は含みません。

## 検証

`npm test` は既存の世界データ16件に加え、実Rapierによる前進・後退・制動、旋回、壁との衝突、駐車・復帰、坂道での接地と制動を検証します。

`CHROMIUM_PATH=/usr/bin/chromium npm run test:browser -- --grep 'driving:|river:' --reporter=list` は、配置車両すべての置換、実キーによる乗降・運転・視点切替・ポーズ・復帰、HUDと既存の歩行を確認します。運転席・追従カメラ・速度計の画像は `artifacts/driving/` に保存します。
