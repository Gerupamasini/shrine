# 車両制作に参照した資料

確認日：2026-11-13。参照写真を閲覧して形状を制作しました。外部の写真やメッシュは配布GLB・テクスチャに含めていません。メーカーのロゴも再現していません。写真と資料の権利は各権利者に属します。

## 1991年 軽トラック

- [スズキ デジタルライブラリー：キャリイ](https://www.suzuki.co.jp/suzuki_digital_library/1_auto/carry.html#p13)
- [1991年モデル公式写真](https://www.suzuki.co.jp/suzuki_digital_library/images/1_auto/carry/img_13-103.jpg)
- [公式諸元表 103.pdf](https://www.suzuki.co.jp/suzuki_digital_library/pdf/1_auto/carry/103.pdf)

KA・2WDの全長3295、全幅1395、全高1715、ホイールベース1855mmを採用。荷台長1940、幅1330、あおり高さ290mm。公式写真の小型角形ヘッドライト、黒い深いバンパー内の橙色ウインカー、丸みのあるキャビンと窓、薄い荷台を参照しました。

タイヤ外径、前オーバーハング、荷台床高、窓の曲率、内装位置は制作上の推定です。モデルは145mm幅のタイヤを使用しており、KAの5.00-12タイヤの精密再現ではありません。前輪トレッド1205mmを基準とし、モデルの後輪も同値（公式は1200mm）にしています。

[WikimediaのCarry写真](https://commons.wikimedia.org/wiki/File:Suzuki_Carry_1001.JPG) も比較しましたが、灯火の仕様が異なるため、1991年モデルの顔には採用していません。

## 1984〜86年型 小型平ボディ

- [Isuzu Elf：第四世代の変遷](https://en.wikipedia.org/wiki/Isuzu_Elf#Fourth_generation)
- [NHR54 / Elf150 前方写真](https://commons.wikimedia.org/wiki/File:Isuzu_elf_nhr54_1_f.jpg)
- [写真の原寸](https://upload.wikimedia.org/wikipedia/commons/4/41/Isuzu_elf_nhr54_1_f.jpg)

第四世代初期の、上段の横長グリル、下段の左右2灯ずつの角形ヘッドライトと中央5開口、大きいミラーアーム、独立した平荷台を採用しました。1994年に走っている旧型商用車という想定です。1991年型とは表示していません。

全長4690、全幅1695、全高2100、ホイールベース2460mm、および荷台寸法はゲーム用の制作目標値です。写真のNHR54仕様に一致する寸法表は確認できていません。外観資料と確認済み諸元を混同しないでください。

## 130系クラウン ハードトップ

- [Toyota Crown：第8世代](https://en.wikipedia.org/wiki/Toyota_Crown#Eighth_generation_(S130;_1987))
- [S130 Hardtop 前方写真](https://commons.wikimedia.org/wiki/File:S130_Toyota_Crown_Hardtop_1.jpg)
- [S130 Hardtop 後方写真](https://commons.wikimedia.org/wiki/File:S130_Toyota_Crown_Hardtop_2.jpg)

ユーザー指定の1987〜1991年型130系を基準にしています。両写真で、後ろドアは一枚の窓、前後ドア間は細い黒い見切り、後端は幅のある塗装されたCピラーであることを確認しました。誤って追加していた三角小窓を削除し、後席窓の後端を前へ寄せています。写真は外観確認用で、全グレードの装備や寸法を証明するものではありません。
