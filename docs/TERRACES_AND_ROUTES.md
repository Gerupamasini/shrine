# 棚田と里山の道（2026-11-13）

## 調査と設計

- [農林水産省・清水棚田](https://www.maff.go.jp/j/nousin/sekkei/museum/m_siki/74_shimi/)：等高線に沿う曲線の石垣、用排水路と農道を一体で整備する例。
- [新潟県・平行畦畔等高線区画](https://www.pref.niigata.lg.jp/sec/nosonkankyo/1356894465591.html)：画一的な区画は大きな段差やつぶれ地を生む。地形に沿う区画で切盛土を抑える。
- [熊野市・丸山千枚田](https://www.city.kumano.lg.jp/tourism/?content=178)、[丸山千枚田の俯瞰写真](https://photo.mie-eetoko.com/photo/646)：大小の曲線区画、枝分かれする畦、斜面の縁と途中をつなぐ農道を参考にする。実在の棚田をそのまま複製するものではない。
- [林野庁・森林作業道指針](https://www.rinya.maff.go.jp/kinki/seibi/romou_seibi/6_.html)：地形に沿い、縦断勾配18%以下を基本とする簡易な道。
- [北海道森林管理局・壊れにくい作業路](https://www.rinya.maff.go.jp/hokkaido/kikaku/sagyoro.html)：できるだけ循環的な配置とし、地形に沿う線形を採る。

この世界は1994年の架空の東北の集落。現代の大規模な圃場整備をコピーせず、既存の小区画と細い砂利道を残す。道路の寸法・設計はゲーム内の近似であり、実施設計ではない。

## 生成処理

`tools/world/rural.py` に地形を読む経路探索と区画の連結成分処理を分離した。

- 棚田の段は谷底からの相対高度ではなく、平滑化した実際の標高で切る。
- 隣り合う段の横畦はずらす。斜面方位の局所的な変化による区画分断を取り除く。
- 離れている田は別の区画として面積と水平面を計算する。細長すぎて耕作面のない断片を除く。
- 道を先に造成し、田は路肩で止める。道から離れた山中の小さな緩斜面を一律に開墾しない。
- 棚田候補から外れた場所をすべて裸地にせず、実際の耕作地以外は森を残す。
- 農道・林道は沢、屋敷、寺、神社を避け、地形の縦断勾配と切盛土を評価して経路を選ぶ。樹木を道から除外する。

## 周回路

- 東：村道 → 宮沢の農道 → 東の林道 → 南沢の農道 → 村道。
- 北：村道 → 奥沢の農道 → 北の林道 → 村道。
- 川向：集落の北側の道 → 棚田の農道 → 集落の南側の道 → 集落内の道。

`scene.json` の `ruralLoops` に周回路、`roads` に道の中心線・路面・幅を保存。地形、植生、紙地図は同じ中心線から生成する。

## 最新mainとの統合

PR #12 の旧道・不整形の旧来水田・扇状地・分校・消防詰所・水口・竹林・遠景植生、および PR #14 の車両モデルと運転機能を取り込む。生成済み画像を片側から選ぶのではなく、統合した生成処理から地形・植生・地図を再生成する。

- 区画の連結成分を分けても、旧来水田のラベル範囲（300000〜699999）を保持する。小区画用の面積閾値を維持するため。
- 舗装路に接続する農道は、2m以下の間隔で高さを決め、既存の車道・旧道の高さを固定して段差を防ぐ。
- 県道を一部共有する経路では、実際の側溝横断位置を検出して蓋を付ける。
- `node tools/architecture/build.mjs --world-only` で地形に依存する道路・水路等の形状だけを再生成できる。既存の車両モデルとレジストリを保持する。
- 運転テストは固定の8台ではなく、`scene.json` に配置された全車両が運転システムに取り込まれることを検証する。統合対象mainの7台の位置・向きは保持する。

再生成：

```sh
python3 tools/world/generate_world.py
node tools/architecture/build.mjs --world-only
python3 tools/world/bake_map.py
```

検証コマンド：

```sh
python3 tests/rural.test.py
npm test
npm run build
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

ブラウザ検査は、3周回の両方向の連続通行、旧来の歩行経路、車両の乗降・運転・停止・視点切替・復帰を含む。確認画像は `artifacts/terrain/`、`artifacts/driving/` に保存。

## 統合版の検証結果

main `9080f92` を取り込んだ状態で、Python 4件、Node 23件、ブラウザ4件が成功。ビルドも成功。ブラウザでは3周回を各方向とも途中のテレポートなしで歩行した。

棚田283区画、旧来水田225区画を生成。周回距離は東約1,591m、北約809m、川向約486m。分校・消防詰所と軽トラック7台の位置・向きをmainから保持した。
