- **田の稲の縁が浮いていた**：遠景の稲は、田の水準＋0.46mの平らな面（`rice-canopy`）と、その縁に立つ稲の帯（`rice-curtain`）で描く。帯は植生マスクの青（稲の縁までの距離）から等値線で作るが、マスクを2Dキャンバスに描いて読み戻していたため、アルファ（草の密度。田の中は0）で前乗算され、田の中が「稲なし」と読まれていた。帯は約2.5万区間のうち約300区間しかできず、稲の面が泥の上に浮いた板に見えていた。PNGを自前で展開して（`src/world/data.ts` の `decodePng`）そのまま読むようにした。同じ読み方をしていた下層植生（`understory.ts`。スプラットのアルファに入っている層が0の所で、裸地・田・河原の判定が消えていた）も直った。
- **河岸段丘**：川の下がりを2.3〜3.2mから4.7〜5.9mにした（主の段丘崖は4〜6m、田から川の水面まで6〜8m）。2〜3mの段は田から見ると草の土手にしか見えなかった。中位の段丘面も1.45〜2.15mに上げた。崖の線の書き出しは、崖の幅と高さの上限を新しい段に合わせた（西の主の崖が地図から消えかけていた）。

### 2026-11-16：急流工・川への吐口・中位段丘
ユーザーの指示「用水の高めの落差工は斜めで作っていい」「残っている点も作業して」への対応。前回のやり残し（下の「このときのやり残し」）を順に片づけた。
- **急流工**：三面張り水路と支線水路は、段丘崖の大きな落差（2〜3.3m）を落差工の積み重ねではなく1本の斜めの急流工（勾配1:2.3〜1:3.5）で下りる。`stepped_profile` の `chute=(最小落差, 勾配)`：急な区間の足から上流へ、目標の河床より上に出ず、その勾配より急に下がらない最も高い河床（後ろ向きのリプシッツ下限）を取るので、急流工は崖の肩を切り込んで始まる。谷底の小さな落差は従来どおり0.6〜0.75m以下の落差工。模型は斜めの床と側壁（`slab`）、足もとの桝。水面は急流工の上で浅く白く、足で泡立つ。
- **川への吐口**：これまでは堤防の下の箱の中で水面のすぐ上まで下がっていて、落ちる水が見えなかった。護岸のある岸では護岸に開けた箱型の吐口から落とし込み（`wallOutlet`）、土の岸では岸を下り、その下の河原を横切るコンクリートの斜路（`bankChute`）で水際まで下りる。吐口の河床は川の水面より0.45m以上高く保つ（氾濫原の上で河床を持ち上げる）。斜路の開口は `channels.png` に描く。`scene.json` の `channel.outlet` と `channel.chutes`。

### 2026-11-15 後半：河岸段丘・渓流・田と水路の縁
ユーザーの指摘「棚田の縁・側溝・用水付近の地形生成が雑」「支流の落差は落とし込みに」「本流を一段下げて河岸段丘を」「支流は岩の見える渓流に」への対応。
- **河岸段丘**：川・河床・岸・護岸・堰・橋・堤防道・堰の用水路をまとめて2.8m下げ（`RIVER_DROP`）、谷底との間に低い段丘面（氾濫原）と段丘崖を作った。崖の足は蛇行帯の外縁に谷に沿って変わる幅を足した線（`scarp_beyond`）、面は約37°。崖の上下に田・家を置かず、崖の面は途切れ途切れの林と竹。氾濫原には昔のままの小区画の田。橋から上る道と谷の中央の農道から堤防道へ下りる枝道は勾配8〜10%の坂（`grade_limited`）で崖を越え、道の法面は `grade_bench` で切土1:1・盛土1:1.5に整える。地図に土がけの記号。

- **道の勾配**：私道の端が坂の途中の道を平らに均して段を作っていたのを直した（道の上は私道で均さない）。谷の中央の農道は枝道の後にもう一度均す。

### 光と見た目（前回のやり残し1）
- **木の幹が透ける**：原因は幹・枝の筒の三角形がすべて裏返し（内向き）だったこと。両面描画で表示はされていたが、法線が反転して夕日の反対側が光り、夕空を背にした幹が透けて見えた（裏面カリングのUnityでは幹が消える）。生成器（`tools/trees/build-trees.mjs`）の巻き順を直して全樹種を再生成。
- **樹冠の陰影**：葉カードの法線は樹冠の形に沿わせてあるのに、three.jsが裏面で反転していたため、半分のカードが逆に照らされていた。`CROWN_NORMALS` で反転しないようにした（遠景ビルボードの焼き込みも同じ）。
- **光**：空を `kloppenheim_06_puresky`（夏の積雲、太陽高度4.7°、CC0）に替えた。直射光と空の光の比を約2:1から約6:1に、太陽の色を約4000Kから約2900Kにした。露出も調整（`src/engine/lighting.ts` の `tune`）。
- **白壁が黄土色**：漆喰・コンクリートに使うテクスチャがベージュだったため、材質に `saturation`（テクスチャの彩度の残し方）を足して白・灰色にした。
- **林床がオレンジ**：地形の層にも `saturation` を足し、林床の色を茶〜オリーブに。地形の層の定義は `materials.json` を唯一の原本にした（以前はコードと食い違っていた）。
- **広葉樹の「葉の塊」**：葉アトラスの房の輪郭が滑らかな曲線で切られていたため、輪郭に葉の大きさの切れ込みを入れた（`compose_atlases.py` の `ragged_outline`）。

### 河川・水系（①〜⑤、最優先）
- **上沢川**：集落の中心（堰・橋の約280m）だけを直線の改修区間（両岸ブロック護岸、落差工2か所、固定堰）にし、上下流は蛇行する自然の流路にした。水面幅4.3〜6.9m、河床幅10〜19m、瀬0.1〜0.25m・淵最深0.8m。湾曲の外側に淵と削れた岸、内側に砂州と草の州。以前の落差工10か所は2か所に減らし、自然区間は瀬と淵で下る。
- **岸**：自然区間は土の岸。古い空石積みは田に迫る湾曲の外側と洗い場だけにあり、ところどころ崩れて途切れる。西岸の川向の棚田の足元にも途切れた石積み。古い石積みの天端は苔むした笠石。
- **河床**：転石（削れた岸の根元・瀬）、流木（砂州）を追加。
- **沢と道路**：大きい宮沢は県道の短い斜橋（床版・高欄・親柱）の下を、小さい奥沢は暗渠でくぐる。
- **用水**：川から取った水は川沿いの低い田にしか届かないので、高い側の田には沢から引く形にした。奥沢・宮沢を少し登った所の取水堰から幹線用水路（幅0.9m）が県道の下を管でくぐり、県道の盛土の足元を、潤す田より高い水位で流れる（田面を決めた後に水位を決め、下流で地面が高い所は上流側を土手に載せる）。農道沿いに支線水路9本。私道・農道の横断は蓋掛け。地図にも描く。

## 再生成の手順

```sh
pip install -r requirements-assets.txt
npm ci                                    # gltf-transform は devDependencies に入った
python3 tools/world/generate_world.py     # 約2分半。浸食の結果は .cache/ に保存され、2回目以降は再利用
node tools/architecture/build.mjs --world-only   # 地形に合わせる模型だけ（全部なら引数なし）
python3 tools/world/bake_map.py
```

- 木のモデルを作り直すときは `node tools/trees/build-trees.mjs`。
- 空を作り直すときは `.cache/polyhaven/hdri/` にHDRIを置いて `python3 tools/assets/process_textures.py --sky`。
- 葉アトラスは、ベイクから作り直す場合は `compose_atlases.py` が輪郭の切れ込みまで行う。今あるアトラスに切れ込みだけを入れる `--ragged-leaf-only` は一度だけ使う（重ねると切れ込みが増える）。
- `tools/world/__pycache__/noise.cpython-313.pyc` がリポジトリに入っているため、生成後は `git checkout tools/world/__pycache__/` で戻す。

河川の設定は `generate_world.py` の `CHAN_Z0`・`CHAN_Z1`（改修区間）、`MEANDER_L`・`meander_s()`（蛇行）、`REVET`（護岸の区間）、用水は「Irrigation network」の節（川向用水は「The Kawamuko canal」、用水路の開口は `channels.png` を書く所）、林分は `STAND`、集落の性格は `HAMLETS`・`ROADSIDE_SHARE`。
